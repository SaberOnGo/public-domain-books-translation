# 鲍斯威尔第90单元：萨维奇/泰勒斯时间线、希腊文才学与奥格尔索普接口

## 可复用问题族

传记脚注中若讨论诗中人物是否影射现实人物，常会出现时间线、假说、反驳、诗句平行证据和后世编者插话。译文必须稳住专名、日期和引用定位，否则一个译名或金额错误就会破坏整段论证。

## 发现方式

- 扫描影射人物和地名接口：`Thales`、`Savage`、`Cambria`、`Wales`、`second sight`。
- 对照货币和版权数额：`ten guineas`、`£500`、`one shilling`。
- 检查古典/圣经典故与名人接口：希腊文、爱比克泰德、尤维纳利斯、斯威夫特、奥格尔索普、伯克利主教、查尔斯·卫斯理。
- 用 `rg` 查错误译名或半修复残留，如“塞尔斯”“十几尼”。

## 风险

- `Thales` 若译名不稳，会让读者误以为是另一人物，且破坏《伦敦》诗中人物和萨维奇之间的影射讨论。
- `ten guineas` 若写成“十几尼”，金额从精确数变成含糊数量。
- `antedated` / `foreseen` / `second sight` 是鲍斯威尔反驳霍金斯的逻辑链，不能压扁成普通“提前”。
- 长段编者补论中多个“同书”引用和诗句平行证据，容易被过度解释或丢失层次。

## 修复模式

- 影射人物首次写“译名（原文）”，后文统一译名；本单元用“泰勒斯（Thales）”。
- 精确货币保持精确，如 `ten guineas` 译为“十基尼”。
- 民俗/思想术语可保留接口，如“第二视觉（second sight）”，帮助读者理解鲍斯威尔的讽刺。
- 长注中按“霍金斯说法 -> 鲍斯威尔反驳 -> 编者折中 -> 证据平行 -> 克罗克反对 -> 再反驳 -> 斯威夫特可能来源”分层，避免中文变成一团。

## 低 token 审计

```powershell
rg -n "Thales|Savage|Cambria|second sight|ten guineas|塞尔斯|十几尼|antedated|foreseen|Oglethorpe|Charles Wesley" chapters/final chapters/translated
```

凡修复金额、人物译名、影射逻辑或诗句引用，当前轮不能 PASS，必须追加整章复查。
