# 18th-Century Biography: Youthful Classical Translations

## Scope

Use this note when reviewing translated biography chapters that quote a subject's
youthful verse, school exercises, classical translations, or verse headings.

## Defect Families

- Note-marker loss around biographical identifications is common when a paragraph
  opens with a dense office/person phrase. Reconcile all source and target note
  numbers before judging a chapter passable.
- Classical verse names should be stabilized early. Speaker names, poem headings,
  place names, and mythic figures often recur only inside quoted verse, but still
  need the same proper-noun display policy as prose names.
- Old-spelling animal or object words can look like modern adjacent words.
  Example: `grizly wolf` in a Horace translation should be read as a fearsome
  gray/grisly wolf, not as a bear-like image.
- Classical geography terms often need concise Chinese plus first-use source
  support. Avoid adding explanatory geography inside the poem unless the source
  already explains it.
- Do not flatten youthful verse into prose. Preserve lineation, quoted-poem
  status, and a slightly formal poetic register, while still keeping Chinese
  readable.

## Review Checklist

- Compare every poem heading, speaker label, and note marker with the source.
- Build or update glossary rows for classical authors, works, speakers, places,
  and mythic or historical figures that appear in quoted verse.
- Read the poem aloud once after literal fixes. Stiff but meaningful juvenile
  verse is acceptable; opaque machine-like syntax is not.
- Mark any round that changed poem wording or note placement as
  `FIXED_RECHECK_REQUIRED`, then rerun a full-chapter check before PASS.
