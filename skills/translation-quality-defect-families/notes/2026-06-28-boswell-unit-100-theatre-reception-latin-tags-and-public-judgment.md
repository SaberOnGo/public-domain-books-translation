# Boswell Unit 100: Theatre Reception, Latin Tags, and Public Judgment

## Scope

Use this note for eighteenth-century theatrical annotations that combine play
reception, stage-business terms, quoted prologues/epilogues, Latin tags, and
arguments about public judgment.

## Defect Family

1. Short biblical or classical references can become too bare for Chinese
   readers if translated only as a citation. Add a compact sense when the note
   relies on the reference, but avoid importing a specific modern translated
   wording unless the edition requires it.
2. Source-word distinctions such as `soothed` versus `awed` need a bilingual
   interface: keep the source token because the note discusses wording, and add
   an immediate Chinese gloss.
3. Stage-reception notes depend on theatre vocabulary. `pit`, `stock-play`,
   `benefit`, `Epilogue`, `bow-string`, and named roles should be translated
   into readable Chinese while preserving first-use source interfaces where the
   title/person/function may recur.
4. Latin public-judgment tags such as `de gustibus non est disputandum` and
   `Provoco ad populum` should not stand alone. Keep the Latin and add a compact
   Chinese rendering that supports the surrounding argument.

## Review Checks

- For each bare scripture/classical citation, decide whether a short sense is
  needed for the note to function.
- Scan italic or quoted source words; if the prose compares word choices, keep
  the original and add Chinese meaning.
- Build a theatre-interface watchlist before translation: roles, stage spaces,
  performance nights, benefit nights, reception claims, and quoted prologue or
  epilogue lines.
- For public-judgment aphorisms, read the paragraph without the source: the
  Chinese must still convey the argument before the Latin/English helps it.
