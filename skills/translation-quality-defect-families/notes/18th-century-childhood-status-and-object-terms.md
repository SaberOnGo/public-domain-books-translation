# 18th-Century Childhood, Status, And Object Terms

Use this note when reviewing eighteenth-century biography passages about family
status, childhood anecdotes, church life, and domestic objects.

## 中文提示

- `Gentleman`、`Esquire`、`yeomanry` 是身份/社会层级信号，不只是礼貌
  称呼。译文要按语境选择“绅士”“乡绅/先生”“自耕农阶层”等，不要保留
  英文原词挤入正文。
- `common prayer-book` 在英国国教语境中应译《公祷书》；`collect` 可译
  “集祷文”。不要把前者泛化成“普通祈祷书”。
- `kennel` 在旧英国街道语境中常指街沟/排水沟，不是狗舍。
- `petticoats` 描写幼儿时可译“孩童裙装”，不要让现代女性内衣义进入
  童年轶事。
- 童年轶事既要保留鲍斯威尔的性格论证，也要避免把旧式赞叹译成现代
  心理诊断或滑稽化叙述。

## English Note

- Treat status labels and church-object terms as historical interfaces.
- Resolve object words through the scene: `kennel` can be a gutter, and
  `petticoats` can mark early-childhood dress.
- Childhood anecdotes in biography often support character interpretation; keep
  that function without adding modern psychology.
