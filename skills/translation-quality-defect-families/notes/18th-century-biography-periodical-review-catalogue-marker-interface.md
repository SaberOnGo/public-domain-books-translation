# 18世纪传记中的期刊书评目录与标记接口

## 问题族

18世纪传记常把期刊、书评、文章题名、作者归属证据和编辑标记压缩成
一长串目录。翻译时如果只追求中文顺滑，容易把书目清单合并过度，造成：

- 源文章节块与译文块数比例过低，后续审校很难逐项对齐。
- 数字注释在密集书名或作者名旁漏迁。
- 原文星号、剑号等不合规标记被直接带入正文，或被删除后使“我已标明”
  这类句子失去读者接口。
- “内部证据”“承认作者身份”“标记为约翰生所作”等归属判断被弱化为
  普通介绍。

## 发现方式

优先用低 token 审计：

- `npm run check:translation-coverage` 检查段落块覆盖率。
- 用正则比对源文和译文的数字注释序列。
- 用 `rg` 扫描 `Dagger`、`[*]`、`[†]`、星号残留、旧页码和 URL。
- 对照源文中书评清单前后的归属判断句，确认译文仍说明标记发生在原文
  或底本中，而不是让读者以为当前译文还保留了这些符号。

## 修复方式

- 密集书评清单可按源文逻辑拆成两个或多个自然段，但不要改变项目顺序。
- 数字注释必须贴回相应书名、作者或判断句附近。
- 不把 `[Dagger]`、`[*]` 等非批准注号直接迁入读者正文。
- 若原文叙述依赖星号或剑号，译文应改写读者接口，例如“原文中我便
  相应以星号标明”，而不是留下看不见参照物的“我便相应地标明”。
- 书名和刊名使用书名号，首次重要专名按项目策略 3 保留源文括注。

## 复查方式

修复后必须重新做整章复查，而不是只看被拆分或补注的清单段。复查重点：

- 数字注释序列与源文完全一致。
- 书目顺序无移位、无漏项。
- 作者归属判断仍有“内部证据”“承认”“标记”等证据链。
- 删除原文非批准标记后，读者仍能理解标记的来源和作用。
