# 18th-century biography: poetic aliases and masked parliamentary interfaces

## 中文经验

- 问题族：传记正文嵌入警句诗、期刊目录、遮名议会演说时，译文容易把诗化别名当作普通人名，或在 `C----ld`、`N--le` 这类遮名形式附近漏掉原注号。
- 发现方式：先用注号序列比对源文和译文，再人工复核诗句、作品目录、书信引文中带人名、遮名、王号和作品名的行。
- 风险：诗化别名误译会遮蔽历史指向，例如 `Eliza's reign` 在斯宾塞语境中指伊丽莎白女王治世；遮名演说人的注号漏放会破坏编辑证据链。
- 修复方式：诗化别名按上下文译出历史对象，不机械音译；遮名人名保留必要源形接口，并把注号放回源文对应的遮名或动作位置。
- 复查方式：用正则比对全章注号顺序；再扫 `C----|N--|Lord|Duke|Eliza|Maro|Spenser` 等候选，确认源形残留都有首现、遮名或引文接口理由。

## English reusable lesson

- Defect family: In eighteenth-century biography, embedded epigrams, periodical catalogues, and masked parliamentary speeches can cause poetic aliases to be translated as ordinary names, or source note markers near masked names such as `C----ld` and `N--le` to be dropped.
- Find it by comparing source and target note-marker sequences, then reviewing lines that combine verse, work-title lists, masked names, royal names, and periodical letters.
- Risk: A poetic alias can hide the historical referent, as `Eliza's reign` in a Spenser context means Queen Elizabeth's reign. Missing note markers around masked parliamentary names weakens the editorial evidence chain.
- Fix by translating the contextual historical referent instead of mechanically transliterating the alias, preserving masked-name source interfaces when needed, and placing note markers back at the corresponding masked name or source action.
- Recheck with a note-sequence comparison plus targeted scans for `C----`, `N--`, `Lord`, `Duke`, `Eliza`, `Maro`, and `Spenser`, classifying each source-form residue as first-use, masked-name, or quoted-interface evidence.
