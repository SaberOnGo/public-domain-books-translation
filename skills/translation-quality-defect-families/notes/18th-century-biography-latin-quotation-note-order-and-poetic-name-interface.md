# 18 世纪传记：拉丁引文注号顺序与诗行专名接口

## 适用场景

18 世纪英语传记常在文体评论中整段引用拉丁诗，再紧接中文译解；也常引用
献诗、颂诗或讽刺诗，其中人名、地名、神话名密集出现。若先翻译再补接口，
容易出现注号重复、注号顺序颠倒，或为了保留诗行节奏而漏掉本书设定的
首次专名源文接口。

## 问题族

- 当源文注号贴在拉丁原文块末尾时，中文译解不应再次复制同一注号；否则
  源文与译文注号集合相同但数量或顺序会失败。
- 若一句中文为了顺读调换了修饰语位置，要重新核对注号顺序。`GIANTS[651]`
  和 `A GREAT PERSONAGE[652]` 这类相邻注号尤其容易被译成 `[652]` 先于 `[651]`。
- 诗行中的首次专名也受本书专名策略约束。若 `Titian`、`Raphael`、`Steevens`、
  `Jones`、`Camdeo`、`Agra`、`Nile` 等此前未在读者正文自然出现，首次诗行
  仍需给 `中文（source）` 接口；后续诗行可只用中文。
- 已在前文自然正文中完成首次接口的人名，如某些 Johnson 圈人物，可在诗行中
  只用中文，但应通过 `rg` 或译表确认，而不是凭印象判断。

## 低 token 审计

1. 用正则抽取源文和译文所有 `\[(\d+)\]`，比较数量、集合和顺序；数量相同
   不代表顺序正确。
2. 对拉丁/希腊/法语引文块，检查注号只保留在源文对应位置；中文释义若紧随其后，
   通常不再复制同一注号。
3. 扫诗行新增专名：先查 `glossary/proper_nouns.csv`，再用 `rg` 查
   `chapters/translated` 和 `chapters/final` 是否已有自然正文首次接口。
4. 对被诗歌行距影响的专名接口，优先补在首次出现的诗行中，后续同名行不重复。

## 修复模式

- 重复注号：保留源文块中的注号，删除中文释义里的重复注号。
- 顺序颠倒：重组中文句序，使注号按源文顺序出现；不可只交换注号数字。
- 诗行专名：首次出现写 `译名（source）`，同一诗内后续出现用译名。
- 任何注号或接口修复轮都不能 PASS，必须追加整章复查并记录
  `note_marker_sequence_equal: true`。
