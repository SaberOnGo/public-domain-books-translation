# 18世纪传记作品年表与书目接口问题族

## 适用场景

- 英文传记、编者序、附录或校勘材料中出现作品年表、书评清单、
  期刊目录、署名归属表。
- 条目含 `acknowl.`, `intern. evid.`, `Preface`, `Life of ...`,
  长作品题名、旧拼写、贵族/教会/大学/军政头衔。

## 常见风险

- 把年表译成普通项目符号清单，导致读者段落覆盖不足，门禁误判为
  缩译或漏译。
- 为了中文简洁而删去英文原题名接口，使书目证据难以回查。
- 短条目如 `Preface. intern. evid.` 译成“序言。内证。”后过短，
  既不便核对，也可能低于结构覆盖脚本的读者段落阈值。
- 把历史等级称号机械降级，例如把 `Landgrave` 译成普通“伯爵”，
  而不是“方伯”。
- 机械重排 Markdown 时吞掉英文题名空格，形成 `toAbyssinia`,
  `ofthe`, `AdmiralByng` 这类书目接口损坏。

## 低成本发现方法

- 翻译后运行 `npm run check:translation-coverage`，若书目型章节
  段落覆盖不足，先检查短题名是否缺少原题名接口，而不是盲目扩写。
- 用正则扫描英文粘连：`[A-Za-z]{2,}[A-Z][A-Za-z]+`。
- 扫描旧书页码和目录残留：`[Page`, `--`, `acknowl_.`,
  `intern. evid_.`。
- 对称号用小上下文核对：`Earl`, `Lord`, `Landgrave`,
  `Marquis`, `Envoy-Extraordinary`, `Abbé`, `Father`。

## 修复模式

- 首次说明 `acknowl.` = “自认”、`intern. evid.` = “内证”，后续条目
  用中文短标记。
- 年表条目优先写成普通短段落。短题名可保留英文原题名：
  `《布尔哈夫传》（Life of Boerhaave）。自认。`
- 长题名保留中文可读标题，并在括号中给英文原题或关键源题名；
  不把所有解释塞进标题层级。
- 历史称号按制度语境译：`Landgrave of Hesse Cassel`
  译为“黑森-卡塞尔方伯”。
- 机械换行后必须扫描英文题名粘连，再跑覆盖和章节控制门禁。

## 复查要求

- 年号、注号、作品归属标记和旧页码残留逐项核对。
- 书目条目应能从中文回查原题名，且不把源语缩写直接裸留给读者。
- 若发现并修复任何题名、称号或接口问题，该轮不得 PASS；
  必须追加新一轮全章复查。
