# 译本质量评估规则与《痴人之爱》五译本独立评审汇总

日期：2026-05-31

适用范围：本文件用于 LifeBook / 公版书翻译项目中，对不同译本、候选译稿或 EPUB 成品进行质量评估。它可以用于文学作品，也可以扩展到纪实、学术、历史、科学等文本；具体书种可在本规则上叠加专门 profile。

本次评审材料包括 5 个《痴人之爱》中文译本。两个独立 Agent 分别完成评审；Book1、Book3、Book5 可基于抽取文本做全书抽检，Book2、Book4 是扫描 PDF，只能基于渲染页视觉抽样，评分置信度低一档。

### Book1：谭晶华译本，88/100

- 忠实性整体强。叙述者自辩、迷恋、体面话语下的猥琐与失控感保留较好，没有把谷崎的暧昧心理改成现代道德判词。
- 中文成熟，句法有出版控制力，段落推进自然，关键屈服段和拜物段能立住。
- “娜噢宓”强调片假名与洋味，有译名策略，但对普通读者略拗，降低初读亲切度。
- 少数词句偏书面或偏解释，例如“颀长秀丽”“依人小鸟”一类表达，文学润色略满。
- 注释较克制，文本干净，未见 QA 或制作痕迹污染。
- 前置信息与来源说明不如 LifeBook 完整；如果进入本项目体系，需要补齐 source evidence、book-info 与版本记录。

### Book5：LifeBook 书坊 SaberOnGo 译制本，84/100

- 来源、公版说明、译制说明、作者背景和 EPUB 前置页最完整，最符合本仓库生产流程意识。
- 忠实性总体好，关键关系、结尾年龄、叙述视角、时代词处理大体对得上日文底本。
- 中文比 Book3 更自然，叙述推进清楚，官能、支配、屈服关系没有被净化。
- 仍有 AI/校订腔或现代网络口吻风险，例如“油腻的大龄女人”“人这种东西”“女侍的雏儿”等，会把大正语境拉向当代中文。
- 正文内解释偏多，部分应转为短注、章末注或书籍信息页，避免打断小说阅读。
- “小嘛”等绰号处理有辨识度，但普通读者进入成本较高，应在风格层面再判断。
- 作为项目基底价值高；作为文学成品，还需要压缩制作说明、清理机械句、提升关键段落的声调密度。

### Book2：郑民钦/郑明钦译本，76/100，扫描 PDF 暂定

- 文件名与部分书目信息写“郑明钦”，另有外部书目写“郑民钦”；正式引用时应保留异写说明，不强行定案。
- 视觉抽样看，正文是较早大陆出版语感，叙述推进明确，官能描写没有明显删弱。
- 前言和文学批评信息较重，有助理解谷崎，但作为电子阅读入口负担偏大。
- 语言有旧式直白和硬朗处，心理、肉体描写的细腻层次弱于谭晶华译本。
- 扫描 PDF 不能可靠检索，OCR 文本不可用，目录、注释和页码仍受纸书形态限制。
- 只能作旧版译法参考；若要作为质量基准，必须先完成 OCR、抽样复核和全文查错。

### Book4：郭来舜、戴璨之译本，76/100，扫描 PDF 暂定

- 两个 Agent 对文学性判断分歧较大：Agent A 认为样张显示较强小说气，Agent B 认为旧译趣味之外有生硬和解释性问题。
- 可见页中，身体描写、舞会对话和心理推进有旧译时代感，部分词语如“混血儿”“洋人小老婆”等今天看略旧。
- 可能保留了较强的旧式文学气味，但也可能牺牲当代读者的直觉理解。
- 忠实性无法全文确认；扫描样张未见明显人物或数字硬错，但不能排除漏译、错译和术语不一致。
- 扫描噪点、歪斜、页边污染影响电子阅读体验。
- 适合作历史译法抽样，不建议未 OCR 前作为主读版本或项目质量基准。

### Book3：林水福译本，75/100

- 全书文本可抽检，译者信息明确。整体结构完整，有译序和注释，可作普通阅读参考。
- 中文流畅度稳定，但声调较平，叙述者的自我欺骗、滑稽和病态迷恋没有充分拉出层次。
- 存在硬错误：结尾为“娜奥密今年二十三，我三十八”，而其他可对照版本与日文底本语义均应为“三十六”。人物年龄错误属于扣分项。
- 局部表达有现代白话或台版转制痕迹，对大陆简中读者可能略出戏。
- 转换后的 MOBI 文本尾部混入营销/目录式内容，电子书清洁度不足。
- 若作为精校参考，需要逐段回日文核对细微心理、时代词和人物关系。

## 二、通用译本质量评估模型

### 评分总表，100 分

| 维度 | 分值 | 评估问题 | 典型扣分 |
|---|---:|---|---|
| 忠实性与事实准确 | 25 | 是否正确传达事实、人物关系、时间、数字、因果、视角、语气和暧昧程度 | 人物年龄/地点/数字错误；漏译；过度解释心理；把含混处译死 |
| 文学声调与风格再现 | 20 | 是否保留原作叙述距离、节奏、审美结构、讽刺、身体感和心理层次 | 每本都翻成说明文；把官能写俗或写淡；把病态关系道德化 |
| 目标语可读性 | 15 | 译文是否像自然目标语写作，句子是否有呼吸，段落是否能独立阅读 | 翻译腔；长句不断气；省字式提纲；目标语标点和语序别扭 |
| 读者体验与吸引力 | 15 | 是否能吸引目标读者继续读，关键场景是否有画面、张力和记忆点 | 关键句平；人物声音不分；开头劝退；注释打断阅读 |
| 术语、文化与注释策略 | 10 | 人名、地名、时代词、制度词、文化词是否统一且服务阅读 | 译名摇摆；正文括注过密；百科式长注；无必要源语裸露 |
| 出版与电子书质量 | 10 | EPUB/PDF/版式/目录/前置页/元数据/版权来源是否干净可用 | 乱码；旧纸书页码目录；制作痕迹；不可检索扫描；metadata 缺失 |
| 可验收证据 | 5 | 是否有来源证据、底本说明、审校记录、抽检闭环和版本记录 | 无底本；无 rights check；无抽检；无法复现评分 |

评级建议：

- 90-100：A，优秀成品。可作为公开阅读本或质量标杆，但仍需常规校验。
- 80-89：B，高质量可用。适合发布或作为基底，但需要精修若干风格/出版问题。
- 70-79：C，参考价值明确。可读或可参考，但存在硬伤、风格不足或电子书体验问题。
- 60-69：D，仅限研究或局部参考。不能作为主读版本。
- 0-59：F，不可用。误译、漏译、机器腔、版权/来源或出版问题严重。

### 一票否决项

出现以下问题时，不能仅靠总分通过；必须返工或降级为“仅供研究参考”：

- 整段、整节、整章漏译。
- 人物年龄、身份、地名、时间、数字等关键事实错误。
- 把叙述视角从第一人称改坏，或替原文加入现代道德诊断。
- 明显机器翻译腔，无法作为自然目标语作品阅读。
- 官能、暴力、支配、羞耻、压迫等结构性内容被净化、加重色情化或改写成立场宣言。
- 正文混入制作日志、prompt、QA 报告、扫描说明、盗版站信息或模板说明。
- EPUB/PDF 结构损坏、严重乱码、目录不可用、缺少关键章节。
- 公版/授权/私人自用边界不清，来源证据不足。

## 三、评估流程

### 1. 先确认材料类型

评估前必须记录：

- 版本来源：出版书、EPUB、MOBI、扫描 PDF、OCR 文本、项目自制 EPUB。
- 译者/译制者：若书目信息存在异写，原样记录并标注来源差异。
- 可检索性：全文可抽检、OCR 可用、仅图像可见，还是结构损坏。
- 底本状态：是否能拿到原文底本、是否有来源与权利证据。
- 评估置信度：高、中、低。

扫描 PDF 原则上不能与可全文检索 EPUB 做同等强度评分。扫描本若要进入正式排名，至少应完成 OCR、版面复核、章节完整性检查和抽样对照。

### 2. 分层抽样

推荐抽样层：

- 开头：前 3-5 个叙述段，检查读者入口和声调建立。
- 人物关系段：称谓、亲疏、支配/服从、年龄、身份。
- 高风险文学段：官能、羞耻、暴力、不适、欲望、幻觉、讽刺。
- 文化时代词：货币、制度、旧称谓、职业、学校、交通、娱乐。
- 对话段：人物声音、时代口吻、自然程度。
- 章节结尾和全书结尾：收束力度、事实数字、主题回响。
- 注释、前置页、metadata、目录、版权/来源说明。

每轮至少由两个独立评审者或 Agent 完成；二者不得共享中间判断。若分歧超过 8 分，必须记录分歧原因，而不是只取平均数。

### 3. 错误分级

| 等级 | 定义 | 处理 |
|---|---|---|
| P0 | 版权/来源不清、整章缺失、结构损坏、严重误导读者的事实错误 | 停止发布，必须修复 |
| P1 | 关键事实、人物关系、叙述视角、风格功能被破坏 | 修复后重评相关章节 |
| P2 | 影响阅读的翻译腔、术语不一、注释扰民、段落不顺 | 进入精修清单，修复后抽检 |
| P3 | 局部可优化表达、轻微标点或格式问题 | 可批量修订 |
| Note | 风格偏好、历史译法差异、可接受替代译名 | 记录，不强制修 |

### 4. 结果输出格式

每次评估至少输出：

- 版本、译者/译制者、文件路径或书目信息。
- 总分、分项分、评级、置信度。
- 4-8 条高信号发现，覆盖忠实性、文学性、可读性、读者体验、基本错误、电子书体验。
- 一票否决项或 P0/P1 清单。
- 与其他版本的相对位置：主读本、精校基底、旧译参考、历史译法参考、不可用。
- 是否需要 OCR、全文复核、日文/源文回查、EPUB 修复或重新发布。

## 四、理论与项目规则依据

本规则综合以下方法，但以 LifeBook 项目可执行门禁为最终落点：

- 本仓库 `template/epub_pipeline/common/references/quality_gate_framework.md`：来源证据、章节全量检查、随机抽检、发布门禁。
- 本仓库 `template/epub_pipeline/targets/zh-Hans/quality_framework/references/quality_standard.md`：准确、通达、风格、审美、可出版。
- 本仓库 `template/epub_pipeline/Japanese-to-Simplified-Chinese/references/quality_standard.md` 与 `japanese_source_notes.md`：日语省略、敬语、汉字词、官能与心理描写边界。
- MQM / Multidimensional Quality Metrics：把翻译错误拆成准确性、流畅性、术语、风格、locale convention 等可标注问题。
- ATA Framework for Standardized Error Marking：把误译、漏译、术语、语法、标点、风格等错误类型化，适合做扣分和复核。
- Juliane House 的 Translation Quality Assessment：强调源文与译文在功能、语域、语篇层面的对应。
- Katharina Reiss 文本类型理论：文学/表达型文本不能只评信息准确，还要评审美功能和读者效果。
- Antoine Berman 的文学翻译批评思路：警惕把原文的异质性、节奏、身体性和暧昧性磨平。

- Juliane House, Translation Quality Assessment 相关书目信息: https://www.routledge.com/Translation-Quality-Assessment-Past-and-Present/House/p/book/9781138795488

## 五、对后续项目的执行建议

- 对候选译本排序时，至少分开两个榜单：文学阅读质量榜、项目生产适配榜。商业优秀译本不一定有完整来源/流程证据，自制 EPUB 不一定已经达到文学最优。
- 对扫描 PDF，先做 OCR 和结构清理，再进入正式质量评分；否则只能标“样张暂定”。
- 对 LifeBook 自制译本，不能只看门禁是否 PASS，还必须引入外部优秀译本的短样本私有对照，用来检查声调、节奏、关键句力度。
- 对日语文学，尤其谷崎这类作品，不能把“通顺”和“干净”误判为“好”。好译文必须同时保留不适、迷恋、身体性、自辩和暧昧。
- 每次评估结果应留下可复核证据，但不要在公开文档中保存长段现代版权译文。短摘引只用于定位问题，优先使用概述、行号、问题类型和修订建议。
