# 俄语底本与来源记录规则 / Russian Source Notes

## 必须记录 / Required Records

- 作者俄文名、中文译名、生卒年。
- 原书俄文题名、初版年份、所用版本年份。
- 来源 URL、获取日期、来源机构或项目名称。
- 来源形态：俄语维基文库校对文本、Internet Archive/图书馆扫描、出版社公版文本、HTML、TXT、TEI、EPUB、纯文本或 OCR。
- 版权口径：来源页面声明、作者死亡年份、出版年份、美国公版状态、中国和 life+70 地区初步判断。
- 若使用扫描和转写并行，写明二者分工：扫描用于图像证据和疑难核对，转写用于分章和翻译。

## 俄语文本风险 / Russian Text Risks

- 19 世纪俄语可能有旧正字法、旧地名、军阶、身份称谓、民族/宗教称呼和帝国边疆语境。
- 俄语旧作可能存在后世删节版、现代化拼写版、章节重排版和编辑注释混入风险。必须记录初版、所用版本和章节结构；不得把删节本当作完整底本。
- Wikisource、在线图书馆或出版社页面可能保留站点导航、原书目录、插图页、校勘说明或项目页文字；不得把站点说明混入正文。
- 俄语旧正字法版本与现代化正字法版本必须记录关系；如果工作文本是现代化转写，应保留扫描/影印证据作为疑难核验来源。
- 小说中的法语夹杂、军阶、父称、昵称、民族称呼和宗教文化词必须记录翻译策略，不能每章临时变换。
- 俄语引号、破折号、省略号、脚注标记和章节题名在转中文时必须重新设计，不能机械保留排版。

## 下载与证据实践 / Download and Evidence Practice

- 若 `Invoke-WebRequest` 或 `curl.exe` 因 Windows Schannel 凭据/TLS 错误失败，不要直接判定来源不可用。先用另一套网络栈验证，例如 Python `urllib.request`，并记录失败命令和可用命令。
- 当工作文本来自 HTML/TXT 转写而另有初版或早期版本影像时，`metadata/source_evidence.md` 应同时记录工作文本 URL 和影像证据线索。
- 若后续需要使用扫描插图、版面图或影印裁图，不能只沿用纯文本权利记录，必须补充图片来源、文件、manifest 和资产门禁。
