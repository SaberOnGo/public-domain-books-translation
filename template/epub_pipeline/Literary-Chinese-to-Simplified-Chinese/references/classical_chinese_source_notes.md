# 文言文来源与底本规则 / Literary Chinese Source Notes

## 来源优先级

公开项目优先使用权利清楚、可核查的来源：

- Wikisource 等明确公有领域或自由许可来源。
- Project Gutenberg 等公版文本。
- 国家图书馆、大学图书馆、Internet Archive 等公开馆藏扫描。
- 权利状态清楚的古籍影印或转写。

## 底本风险

文言文来源常见风险：

- 现代标点和分段被误认为古人原文。
- 现代校注、题解、按语进入正文。
- OCR 或转写错误被直接翻译。
- 繁简转换导致字义或专名混淆。
- 版本异文、删补、篇章顺序不同。

## 现代资料边界

现代白话译文、现代商业校注、现代导读、百科条目、课堂讲义、影视改编资料只能作为背景线索，不能复制其表达，也不能成为隐藏译文来源。

## 古籍版权与整理层边界

古籍原文进入公版，不等于现代整理本的全部文字层都可自由复用。正式项目必须区分：

- 古代原文、公版影印、旧注和旧序跋。
- 现代标点、断句、分段、校勘、注释、题解、白话译文和电子录入贡献。
- 图书版式、站点页面结构、数据库整理、OCR 或协作校录文本。

不要把“出版时间在 50 年以前”简单写成通用公版判断。应按适用法域记录作者保护期、法人/组织作品保护期、版式设计保护期，以及整理、汇编、翻译、注释等派生层的权利边界。若现代整理层权利不清楚，不能把它作为正式底本；只能寻找公版影印、自由许可文本，或由项目基于权利清楚的 witness 自校、自加标点、自定分段。

## Trial Source vs Release Source / 试译来源与正式发布来源

文言文模板建设阶段可以使用可核查的公开网页来源做小范围试译，以测试底本、断句、对照正文和注释策略。但试译来源通过不等于正式发布来源通过。

如果试译使用 Wikisource 等协作转写来源，正式公开发布前必须明确：

1. 是否只把它作为 trial witness。
2. 是否改用公版影印/扫描作为正式 base text，并由项目自定断句标点。
3. 若继续使用协作转写、标点或注释整理，是否满足该站点贡献许可和项目发布许可的兼容要求。

`qa/pretranslation/pretranslation_report.md` 可以使用 `PASS_FOR_TEMPLATE_TRIAL` 表示模板试译通过；只有来源权利、底本、人物/术语记录和试译门禁全部满足时，才允许写 `PRETRANSLATION_PASS` 并进入正式批量翻译。

## 多见证底本选择门禁 / Multi-Witness Base-Text Selection Gate

正式翻译前必须先建立 `metadata/source_selection_report.md` 或等价的本书专项底本比较记录。不得把单一影印本、OCR、网页转写或协作标点直接升格为正式主底本。

报告至少比较：

1. 影印或扫描来源：版本、年代、馆藏或上传方、页码完整性、权利状态、图像清晰度。
2. 可编辑文本来源：是否 OCR、是否人工校录、是否有现代标点、分段、注释和贡献许可。
3. 版本系统：如士礼居、四部丛刊、四库、四部备要、现代整理本等之间的关系。
4. 使用角色：主底本、影印核验 witness、断句/检索辅助、注疏/异文参考，不得混用。
5. 不采用来源的理由：版权不明、现代整理版权、OCR 质量差、版本不合、站点许可不兼容等。

若用户、审校者或 agent 质疑“为什么用这个 PDF/扫描，是否有更好的文本”，不得只回答“因为能下载”。必须在 `metadata/source_selection_report.md` 或等价复审文件中区分：

- 影印 witness：用于核验字形、页码、卷次、篇章、注层和异文线索。
- 正式可编辑文本：由项目自录、自校、OCR 后人工校或经许可的可靠文本产生。
- 网页转写或协作标点：只能在 license、底本、转写质量、标点/分段贡献边界清楚后采用；否则只能作检索和校勘辅助。
- 不采用看似“更好/更方便”文本的理由：版本不合、权利不明、站点限制、现代整理成分、OCR 或协作转写风险。

对于《战国策》《史记》《左传》这类已有多种电子文本和影印本的作品，默认不应把扫描 PDF 作为唯一日常输入。更稳妥的正式路线通常是：权利边界可记录的电子工作文本 -> 项目自定断句标点和分段 -> 多 witness 校核 -> 影印页图控制。扫描本仍然必须保留，因为它能防止电子文本误字、误分段和注正文混淆。

`PRETRANSLATION_PASS` 只允许在以下条件同时满足时写入：

- 已选定主底本或明确的主底本组合。
- 每个 witness 的使用角色已写入 `metadata/source_witness_manifest.md`。
- 若使用协作转写或站点文本，已记录许可兼容性；若许可不兼容，只能作为检索和校勘线索。
- 若主底本是影印本，已说明正式可编辑文本如何产生：项目自录、自校、OCR 后人工校，或其他可审计方式。
- 试译章节已经按最终源策略重新核验，而不是只沿用模板试译输入。
