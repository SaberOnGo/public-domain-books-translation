# Full Execution Route / 完整执行路线

Execute this route together with copied common `PIPELINE_SPEC.md`, `automation_contract.md`, and the English target framework. No stage is optional unless common policy explicitly declares it optional. Human checkpoints do not require confirmation when autonomous execution is authorized.

0. Read current policies and record scope, source/target tags, private/public mode, proper-noun setting, requested editions, and forbidden outputs.
1. Ingest the lawful source, preserve immutable bytes/hash/edition metadata, record rights/declaration, classify source artifacts and images. Extract text without silently losing notes or appendices.
2. Split complete source chapters into `chapters/src`, preserve natural paragraphs, headings and image positions, and write source manifests.
3. Research English translation principles and verify relevant external factual references without acquiring unprovided copyrighted full texts.
4. Write book-specific translation research and style profile; record source uncertainties and genre-sensitive risks.
5. Run A/B/C/D pretranslation trials, then the three-category sample test under the English rubric. Record failure, revision and fresh PASS evidence before chapter production.
6. Complete whole-book name discovery, candidate decisions, registry, occurrence ledger, terminology and forbidden renderings; lock translation contract and canonical units. Record current orchestration capabilities and finite plan.
7. Translate each chapter as complete canonical unit patches with one owner; the coordinator alone merges by chapter CAS.
8. Immediately perform common `prompts/08a_chapter_post_translation_control.md`: whole chapter, fidelity, natural English, literary rhythm, senses, terminology, names, titles/navigation, notes, image text interfaces and production traces. Preserve failures; fixes require a new full round. Independent unit semantic evidence and full-chapter review are mandatory.
9. Record separate fidelity, readability, terminology and imagery reviews and current chapter gate. Only zero-issue PASS chapters enter final projection.
10. Write production specification including English typography, cover, frontmatter, assets, editions, all required common/private policies and gate outputs.
11. Build sample EPUB/XHTML with at least one image when present; inspect headings, 390px layout, image paths, notes, metadata and reader boundaries. Record sample review.
12. Rebuild clean staging and full enabled EPUBs; run template/private preflight, publication/asset/cover/reader checks, canonical artifact verification, bilingual adjacency/integrity and EPUBCheck on each edition.
13. Perform whole-book literary refinement and opening reread; record `qa/literary_style/literary_style_review.md`, refinement evidence, and actual effort metrics.
14. Dispatch two independent final reviewers for content and engineering; preserve review/scorecards and route failures to the responsible stage.
15. Execute common `prompts/16a_stratified_random_spotcheck.md`: current-run deterministic stratified samples, independent A/B scored reviews, same-round book-wide family audit/repair/exception/closure, skill backfill, rebuild and fresh seeds. Default exit: latest two current-run consecutive PASS rounds, all families closed, confidence >=0.80 and excellence validator PASS.
16. Rebuild both enabled editions after closure, rerun all affected gates, and verify hashes and complete source scope.
17. Create versioned artifacts using common release policy or private `private:artifact:create`. No GitHub/public shelf for private content. Do not overwrite prior artifacts.
18. Write final manifest, final quality score, revision route, book retrospective and reusable template suggestions. Verify every common Done requirement and process cleanup before DONE.

按此路线完成全部阶段；不得用结构 PASS 代替语义复核，不得把抽检当作主要润色流程，不得伪造已执行检查。新英文模板仍使用所有 common 硬门禁。
