# 法语模板实践复盘

本文件记录可复用的法语到简体中文模板经验。具体书籍的制作日志、原文、译文、QA 和 EPUB 输出不得写入本文件。

## Reclus《Histoire d'une montagne》实践入口

status: "TRIAL_LESSONS_STARTED"

### 2026-05-30 试译复盘

- `Histoire de ...` 在自然写作中不应机械译成“……史”。Reclus 本书的中文题名暂定《一座山的故事》，因为它是自然过程、个人经验和山地生活的综合叙事。
- 法语自然地理散文的核心处理顺序应是：先保留观察者的空间移动和画面，再锁定地貌/水文/冰雪术语。只追求术语准确会把文本压成教材。
- `rayée de sillons`、`s'arrêtait brusquement`、`moins hauts, mais plus rapprochés` 这类句子要求译者处理视觉透视和动作，不宜译成静态说明。
- `éboulis`、`ravin`、`défilé`、`contrefort`、`glacier`、`moraine` 等自然地理词必须早期进入术语表，并设置正文呈现策略。
- Gutenberg 文本可能来自 BnF/Gallica 图像；工程中应把 Gutenberg 纯文本作为工作底本，把 Gallica/BnF 作为图像证据线索记录。若后续直接使用扫描图或插图，必须另走资产和权利记录。
- Windows PowerShell/curl 在某些环境可能因 Schannel `SEC_E_NO_CREDENTIALS` 下载失败；不要把它误判为来源不可用。可以改用 Python 标准库下载，并在 `source_evidence.md` 记录下载方式和错误。

### 待完整制作后继续回填

- 第 2 章已暴露更高密度地貌词：`cirque`、`vallon`、`gorge`、`arête`、`croupe`、`ressaut`、`alluvions`、`anfractuosité`、`pâtis`。法语自然地理模板必须要求早期术语表，而不是等全书翻完后再统一。
- 第 2 章也证明：法语远景/近景/高处俯瞰句必须按观察位置组织中文。若只按法语句法顺序贴译，会丢掉“从平原看、从木屋看、从峰顶看”的视角变化。
- 自然地理散文中偶发英文残留或法语裸词会破坏读者信任；每章译后控制应增加 `rg` 式裸外文复扫，排除必要的 URL、文件名、专名和术语表之外的正文外文。
- 第 3 章进入岩石、矿物和 19 世纪化学解释后，模板需要明确：专业术语必须早期锁定，但不能用现代知识替作者改写。像 `augrite` 这类旧矿物名应先译成现代近似通行名并路由技术复核。
- 第 3 章还说明，自然科学段落仍要保留 Reclus 的文学比喻，例如黑玉王冠、薄纱雪原、荒废城市和宝藏洞穴；不能因术语密度上升而把章节压成矿物学条目。
- 第 4 章证明，法语自然科学散文常把神话解释、民间想象、古典典故和旧科学假说放在同一论证链里。模板应要求译者保留层次：神话是神话，推测是推测，19 世纪科学假说是作者时代的知识框架，不得改写成现代板块构造说明。
- 第 4 章的 `trapp`、`métaphyre`、冷却收缩假说等内容需要“先可读译出，再路由技术复核”。旧地质名和旧假说不能卡死每章译后门禁，但必须阻断终稿/release 之前的专业复核遗漏。
- 第 4 章还说明，专名与典故密集段应保持正文顺滑，避免把所有原名括注塞进正文。需要说明的内容应进入译注/术语表，而不是破坏叙述节奏。
- 第 5 章说明，自然史段落的翻译不能只建立术语映射，还要保住论证路径：日常可见的水沟沉积、海底堆积、化石保存、相对年代判断、高山化石证据。法语长句可拆，但观察和推理的顺序不能散。
- 第 5 章的 `animalcules`、`organismes inférieurs`、`branchilles` 等词暴露了旧自然史分类风险。模板应要求把时代性术语单独路由：正文先给可读中文，术语表记录历史语境，终稿前再判断是否需要译注。
- 第 6 章证明，同一章可能同时包含宏观地貌史、第一人称现场、物理化学解释和神话收束。中文必须保留段落功能差异：现场段要有声音、触感和运动；解释段要清楚；神话段要承担结构收束，而不是被当成可删装饰。
- 第 6 章还说明，作者时代性地质说法可能嵌在高质量文学段落里。模板应允许章级门禁“可读通过并路由专业复核”，但必须阻止带着未复核旧说直接进入终稿/release。
- 第 7 章说明，自然灾害散文不能只译地貌过程。山崩机制、居民无法迁离的处境、夜晚钟声、巨石下逃生、历史传说和多年后的景观恢复共同构成章节价值；删减其中任一层都会把散文压成科普摘要。
- 第 7 章的 `clapier`、`lapiaz`、`chaos` 表明，区域性地貌词应先按上下文给出可读中文，再在术语表路由专业复核。不能为了显示原文准确，把多个法语词直接堆进正文。
- 第 8 章说明，气象科普段仍然依靠视觉结构成立：城市污浊空气与峰顶纯净空气、夕照雪峰与暮色平原、石山与水汽山、云的头巾与火山状喷发。模板应要求先保住对照和运动，再整理术语。
- 第 8 章也暴露时代性气象解释风险。像云与岩石“相反电性”吸引这类说法应忠实译出并路由复核，不能悄悄改写，也不能不加判断地当成现代知识发布。
- 第 1-8 章重审暴露出一个流程错误：生成 `control.md`、readability、imagery 和 gate 文件，不等于完成每章译后质量门禁。模板已强化为“逐段对照 -> 发现问题 -> 修复正文/接口 -> 追加复查轮次 -> 最近一轮无阻塞项后才允许继续”。
- 第 5 章重审发现 `branchilles` 被误译为“鳃”，正确语境是植物化石中的“细枝”；同时修复“无数百万个世纪”为“数百万个世纪”。这类错误不会被文件计数发现，必须依靠逐段语义复核。
- 第 9 章执行强化后的强制门禁时，复读发现 `l'éclat du tonnerre` 初稿被译成“雷鸣的闪耀”，中文误带视觉含义，已改为“雷鸣的炸响”。这证明即使原文覆盖完整、自动扫描通过，仍必须做人工语义复读。
- 第 9 章说明，雾与雷暴段落需要同时保留感知失真、身体危险、云海视觉、时代性气象解释和第一人称情绪。不能把雾中错觉、雾幕巨影或风暴声响删成天气知识摘要。
- 第 1-9 章再次执行逐章语义重审后，共修复 12 处问题。问题类型包括误译、法语结构干扰、中文搭配不自然、被动结构缺失、感官通道误判和专名语体偏差。结论是：段落计数、裸外文扫描和文件计数只能作为辅助证据，不能替代逐段复读。
- 后续每章必须采用固定顺序：翻译当前章 -> 逐段对照原文 -> 修正文 -> 自动扫描 -> 在同一 control 写入问题、修复和复查结论 -> 才能读取下一章。
- 门禁闭环进一步收紧：发现问题并修复的那一轮不能直接 PASS。必须追加一轮独立的整章全量复查；若仍发现问题，再修复并继续追加。只有最后一轮全章零问题，才可继续下一章。
- 第 1-9 章中文成稿润色闭环共修复 26 处翻译腔或不自然表达。模板必须把“忠实准确”和“中文自然流畅”视为两个同时满足的条件；只做到语义正确仍不能 PASS。
- 第 10 章首次完整执行新门禁：round 1 全章检查修复 7 处，记录为 `FIXED_RECHECK_REQUIRED`；round 2 再次通读整章，零问题后才 PASS。动物名 `marmotte`、`chamois` 分别校正为“旱獭”“臆羚”，说明自然史词汇也必须进入逐章术语复核。
- 第 15 章说明，动物名、旧民族称谓、旧长度单位和雪上微生物词不能等终稿再统一。`Ostiak`、`lieue`、`neige pourrie` 一类词应在本章译前或译后立即进入术语表，正文先给自然中文，时代性或俗称边界留给译注/术语表处理。
- 第 15 章还说明，Reclus 对猛禽、熊、狼和臆羚的描写带有强烈道德化和讽刺语气。中文润色不能把这种语气抹成中性自然史说明，也不能为了生动新增原文没有的动物行为；应保留“自然史观察 + 社会象征批评”的双重声调。
- 第 16 章说明，法语植物地理段落常用“海拔变化模拟纬度变化”“植物殖民地”“植物军队进退”等大比喻组织科学解释。中文应先保住解释链和比喻链，再处理术语；不能把它改成现代地理教材式摘要。
- 第 16 章暴露出术语表自身也需要章级质量检查：新增术语后必须检查 `source_term` 是否重复。重复条目会让后续正文禁用写法、终稿术语统一和自动门禁判断漂移。
- 第 16 章的人类迁徙类比和第 17 章的自由山民段落涉及 19 世纪 `race`、民族、征服、边界等社会术语。模板应要求忠实呈现时代语气，但用中文控制现代误读风险；需要说明时进入术语表或短注，不在正文加长解释。
- 第 17 章说明，封建建筑和社会身份词必须逐章建表：`donjon`、`meurtrière`、`herse`、`oubliette`、`vassal`、`bourgeois`、`manant` 等词若不锁定，会在“主塔/城堡/地牢/暗牢/农民/贱民”之间漂移。
- 第 17 章还说明，术语表的 `forbidden_body_renderings` 不是摆设。若 `oubliette` 禁用“地牢”、`scolopendre` 禁用“蜈蚣”，每章 PASS 前必须扫描正文是否命中禁用写法；发现后修正文，并追加下一轮全章复查，不能在同一轮直接 PASS。
- 第 17 章废墟、暗牢和泉水传说段证明，历史社会散文也要“有画面”。建筑术语可以准确，但井沿、舌蕨、浮萍、壕沟、暗牢气味和泉边水芹等具体物象不能被抽成制度说明。
- 第 18 章说明，历史医学和残障相关称谓必须同时处理“忠实”和“现代误读风险”。`crétin`、`idiot`、`crétinisme`、`goître` 一类词不能用现代辱骂词替换，也不能改写成现代百科口吻；正文先用克制稳定译名，术语表记录历史语境、禁用写法和终稿短注需求。
- 第 18 章还说明，旧医学病因假说与社会卫生观察要保留作者时代链条：饮水缺碘、雪水未充分接触空气、含镁岩石、阴湿住房、畜棚地窖和收容院改革共同构成论证。中文可以通俗顺读，但不能把它压成“缺碘导致疾病”的现代单因解释。
- 第 18 章的强烈身体描写和道德反省段需要特别复读。模板应要求译者保留 Reclus 的时代性冲击、同情和社会批判，同时修掉法语句法残留，让读者能读下去，而不是被粗糙直译或过度现代化判断绊住。
- 第 19 章说明，宗教史、神话和旧地名转写密集章节必须把专名术语表当作当前章门禁的一部分。印度、锡兰、中国、日本、近东和基督教传统中的神名、山名、民族称谓和文献名若不建表，后续会在音译、意译和通行名之间漂移。
- 第 19 章还暴露出“原文疑点”不能靠正文硬改。类似 `Choung`/舜帝“四百三十年前”这种与常识冲突的底本文字，应在正文标明“原书称”并路由影印核对/终稿译注，不能无证改成现代正确版本，也不能让读者误以为译者断言。
- 第 19 章的山岳显现、神话枚举和诗句说明，宗教史段落也要保留散文节奏。中文可拆长句、补顺连接，但不能把奥林匹斯、须弥、泰山、富士山、亚拉腊、西奈等意象压成干瘪百科条目。
- 第 20 章说明，希腊神话专名和宗教替换链应按章即时建表。奥林匹斯、泰坦、宙斯、赫拉、时序女神、百牲祭、普罗米修斯、圣三一、狄俄尼索斯、阿索斯、阿斯加德和世界树等词若后置处理，会让正文在神话、宗教史和地理之间漂移。
- 第 20 章还说明，`barbares`、`éther`、`mirmidons` 这类看似普通的小词可能承载时代视角、古典宇宙观或典故。章级门禁应把它们纳入术语表和禁用写法，而不是只锁定显眼神名。
- 第 20 章诸神享乐与人间苦难对照段需要保留讽刺力度。中文润色要让句子顺读，但不能削弱 Reclus 对奥林匹斯诸神旁观战争、贫困和普罗米修斯受难的批判性声调。
- 第 21 章说明，民俗和宗教替换章节不能只翻“神/精灵/魔鬼”几个大词。`génies tutélaires`、`dieux de contrebande`、`sabbat`、`incantation`、`Vierge Chrysopolite`、`Grütli`、`Tell` 等小型术语决定语气和历史层次，应在当前章建表。
- 第 21 章还说明，术语表重复会在后期积累成质量风险。新增常见地质词如 `schiste` 前必须扫全表，发现重复应立即合并，不等全书统稿。
- 第 21 章的德国沉睡皇帝与瑞士三人传说证明，Reclus 的政治讽刺常藏在民间传说里。中文应保留“等待屠杀”与“等待自由”的对照，不能把它们改写成中性民俗摘要。
- 第 22 章说明，终章思想收束不能只当散文结尾翻译。登山、测绘、山地铁路、水力采矿、自然教育、所谓文明民族、改造自然和孤独退隐共同构成 Reclus 的社会地理思想链，术语和句法都要服务这一链条。
- 第 22 章还说明，现代技术段落需要双重控制：一方面要把 `locomotive de montagnes`、`ascenseur mécanique`、`terrain de transport`、`brise-lames` 等术语译准；另一方面不能把作者对进步滥用、教育和自然美学责任的批判削成技术说明。
- 第 22 章的书末 `FIN`/“完”应在段落覆盖中作为终止标记排除。否则机器计数会误报译文多一段，章节控制应记录排除规则。
- EPUB 后人工试读返修说明，读者可见前置页绝不能泄露内部命令。诸如“读得顺、有画面、不费劲”这类给译者/AI 的执行要求，只能留在模板、prompt、QA 或复盘中，不能写入 `book-info`、`translator_note` 或正文。读者版说明应只交代底本、术语原则、版本边界和必要语境。
- 法语到中文自然散文尤其容易滥用中文分号来模拟法语长句层级，但“零分号”也会把中文排比句硬拆成仓促短句。面向简体中文出版文本时，分号应视为高风险标点：`lint:publication` 使用默认数量上限统计滥用，人工逐例证明必要；排比、并列分层、对照句群中必要的中文分号可以保留，并须复读确认节奏自然。
- EPUB 后读者试读能暴露章节级门禁没有覆盖到的“整书压迫感”。自然地理散文不应把长段连续压进屏幕。全书成稿阶段应扫描正文段长，超过约 330 个中文字符的段落必须人工判断是否按自然句界拆分；拆分只改变阅读呼吸，不改变术语、论证顺序或专业层级。
- 封面文字排版不能只看脚本通过门禁。若作者、译制者或来源说明压在山体、溪流、森林等主视觉上，即使可读也会显得廉价和不协调。法语自然写作类封面应优先使用上下留白或稳定信息区，让山景承担主视觉，让文字承担书籍身份。
- 随机抽检前若收到用户全书质量反馈，既有随机轮次和 DRAFT release 必须失效，不能继续沿用。修复后应重建 EPUB，再用新 seed 生成新 round；旧 round 只能作为历史风险输入，不能作为通过证据。
- 抽检闭环不能只修正文，还要同步修术语表。第 5 轮发现 `chamois` 译作“臆羚”对普通读者不直观，正文改为“欧洲山羚”后，术语表也必须把旧写法列入禁用正文写法，否则后续章节或自动流程可能把旧问题带回正文。
- `Arabie Pétrée`、`Choung` 这类旧地名/旧转写的修复不能只改抽中段落。模板应要求同时检查术语表的默认译名、禁用写法和译注策略，避免“石质阿拉伯”“舜帝”等未闭环判断在后续统稿中漂移。
- 随机抽检 PASS 只能来自“返工后新 seed + 两个独立 Agent 同轮 PASS + `review:random-validate:pass`”。若某轮一个 Agent PASS、另一个 Agent FAIL，整体仍是 FAIL；旧轮闭环文件只能证明已知 P2 被修复，不能替代下一轮新 seed 抽检。
- release note 不应只记录“创建版本化 EPUB”。正式 PASS release 必须写明读者可见修复、抽检轮次、返工闭环、EPUBCheck、publication lint 和剩余非阻塞风险，让后续读者反馈能直接进入下一 patch 版本。
