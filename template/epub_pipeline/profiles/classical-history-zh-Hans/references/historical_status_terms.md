# 历史制度与身份词译法示例 / Historical Status and Institution Terms

本文件收存原先写在英译中通用模板里的个案规则。通用模板只保留原则：制度身份词正文按语境意译，原词与理由放进本章注释或术语表。具体书籍按需从这里取例，并把本书写法记入本书 `glossary/terms.csv`（含 `forbidden_body_renderings`）。

This file holds case rules that used to sit in the generic English-to-Chinese template. The generic template keeps only the principle: translate status and institution terms by context in the body; keep the source term and rationale in a chapter note or glossary.

## 盎格鲁-撒克逊 / Anglo-Saxon

- `thegn` / `thane`：正文不音译为“塞恩”，也不统一泛译为“支持者”。语境强调土地、等级、服役和政治义务时，按上下文用“王室领主”“领主近臣”“盎格鲁-撒克逊领主”等；术语注写明原文作 `thegns`，又作 `thanes`。只有专门讨论词源、译名分歧或英文文献术语时，才可在正文短括注原词。
- `witenagemot`：正文用“贤人会议”，原词放术语注。
- 建议禁用或需复核的正文写法：`塞恩`、裸露的 `thegn` / `thane` / `witenagemot`、无理由的 `王室领主（thegn）`、作为统一译名的 `支持者`。

## 使用方法 / How to use

1. 只有本书确实出现这些词时才引用本文件。
2. 把选定写法与禁用写法写入本书 `glossary/terms.csv`；章节门禁按本书术语表检查，而不是按本文件。
3. 发现新的同类词（如罗马的 `cliens`、`patronus`，中世纪的 `villein`），按同一格式追加到本文件，不要写回通用模板。
