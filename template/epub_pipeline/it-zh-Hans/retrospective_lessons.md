## Salgari《Le tigri di Mompracem》实践入口

status: "TRIAL_LESSONS_STARTED"

### 初始预期

- Sandokan 系列属于强情节冒险小说。模板必须同时控制动作推进、对话称谓、殖民时代地名/族群/宗教词和中文阅读节奏。
- 试译应优先选择句法密集、动作链密集、殖民语境和感叹/对话较多的章节，而不是只选开篇。
- 每章译后质量控制必须把“中文是否顺、有趣、不费劲”作为硬要求，但不能把海事、武器、殖民机构、地理和族群称谓随意通俗化。

### 2026-05-31 第 23 章试译复盘

- 第 23 章 `Yanez alla villa` 是合适的最难试译章：它同时包含潜入伪装、长对话、女性人物心理、Sandokan 身世辩护、英殖民护卫队调度和结尾伏击战。意大利语模板不能只准备“文学句法”规则，还必须准备“冒险叙事动作链”和“殖民时代称谓”规则。
- Yanez 的中文声调不能译成严肃报告。他的核心功能是冷静、机智、带一点调侃；即使在欺骗勋爵时，也要让读者感到他在临场表演。
- Marianna 的段落不能只译成“等待被救”。她同时有反抗、恐惧、对叔父的亲缘牵连、对未来的不确定和对 Sandokan 的选择。中文润色要保留这种矛盾，不把她压成单一恋爱功能。
- Sandokan 身世叙述是本书重要合法化链条：王族出身、殖民势力/本地盟友击垮其王国、家人被杀、流亡、复仇、成为马来亚之虎。译文可以顺读，但不能把这段压缩成“他有悲惨过去”。
- 战斗段必须先锁动作顺序再润色：口哨 -> 双侧枪声 -> 人马倒地 -> Yanez 护住 Marianna -> 勋爵开枪/决斗 -> 英国士兵受命杀 Marianna -> Sandokan 冲入救人。若先追求“热闹”，很容易改乱因果。
- 自动扫描是必要但不充分。第 23 章 round 1 发现英文 `barricade` 残留并修复；这证明每章 control 必须同时做裸外文扫描和人工语义复读。
- `prahos`、`kriss`、`rajah`、`Tigre della Malesia`、`Labuan`、`Sarawack`、`Varauni` 等不能等全书翻完再处理。试译阶段就要进入术语表，并用 `review` 状态阻断终稿前遗漏。
- “顺、有趣、不费劲”不是把术语压扁。比如 `kriss`、`prahos`、`rajah` 不能都译成“刀”“船”“王”；正文可自然读，术语表和短注要承担精度。
