# 06 术语、专名与文体锁定 / Glossary and Style

## 输入

- `qa/pretranslation/pretranslation_report.md`
- `metadata/style_profile.md`
- `glossary/terms.csv`

## 任务

1. 根据试译结果修订 `metadata/style_profile.md`。
2. 更新 `glossary/terms.csv`，覆盖人名、地名、国名、官名、爵位、制度、典故和核心动词。
3. 记录首次出现策略和注释策略。
4. 若叠加历史 profile，同步 `glossary/historical_terms.csv` 和 `glossary/people_places.csv`。

## 门禁

核心人物、国家、官名和制度词未锁定时，不得批量翻译。
