# 意大利语底本与来源记录规则

本文件只记录意大利语原文进入简体中文时容易出现的源语言和来源风险。更通用的简体中文译文质量规则见 `template/epub_pipeline/targets/zh-Hans/quality_framework/`。

## 必须记录

- 作者意大利文名、中文译名、生卒年。
- 原书意大利语题名、初版年份、所用版本年份。
- 来源 URL、获取日期、来源机构或项目名称。
- 来源形态：Wikisource 校对文本、Project Gutenberg 文本、Internet Archive 扫描、Liber Liber 文本、HTML、纯文本、TEI/XML 或 OCR。
- 版权口径：来源页面声明、作者死亡年份、出版年份、美国公版状态、中国和 life+70 地区初步判断。
- 若使用扫描和转写并行，写明二者分工：扫描用于图像证据和疑难核对，转写用于分章和翻译。

## 意大利语文本风险

- 19 世纪和 20 世纪初意大利语可能有旧拼写、旧标点、长破折号、密集感叹、地区词和殖民时代称谓。
- Wikisource 页面可能保留站点模板、校对说明、目录、版本说明和协作转录信息；不得把站点说明混入正文。
- Project Gutenberg 或其他纯文本必须剥离许可证头尾，但来源证据必须保留。
- Liber Liber 等站点的权利声明和文本授权必须单独记录；若授权与本项目发布方式冲突，应停止或改用公版扫描/其他合法底本。
- 影视改编、现代插图、现代中文译本、现代英文译本、商业 EPUB、盗版站和不明 OCR 不得作为底本。
- 不得使用现代中文译本、现代商业校注本或现代改写本作为隐藏参考材料。

## Salgari / Sandokan 冒险文本风险

- Emilio Salgari 和 Sandokan 系列常含殖民时代地名、英殖民机构、民族/宗教称谓、海盗/私掠语境、船名、武器、头衔和热带地理词。
- `Sandokan`、`Mompracem`、`rajah`、英国殖民官职、马来/印度/婆罗洲相关地名和族群名必须早期进入术语表。
- 冒险场景的动作链要保留推进和紧张感，不能翻成动作清单；但也不得新增原文没有的血腥、情色或民族刻板细节。
- 殖民时代偏见应忠实呈现并通过短注控制误读，不得净化、猎奇化或替作者现代化表态。

## 下载与证据实践

- 若 `Invoke-WebRequest` 或 `curl.exe` 因 Windows Schannel/TLS 错误失败，不要直接判定来源不可用。先用另一套网络栈验证，例如 Python `urllib.request`，并记录失败命令和可用命令。
- 若使用 Wikisource 工作文本，必须记录章节 URL、页面版本/获取日期和该文本与初刊/扫描底本的关系。
- 若后续需要使用扫描插图、版面图或影印裁图，不能只沿用纯文本权利记录，必须补充图片来源、文件、manifest 和资产门禁。
