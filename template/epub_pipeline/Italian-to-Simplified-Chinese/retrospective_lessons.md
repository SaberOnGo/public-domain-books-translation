# 意大利语模板实践复盘

本文件记录可复用的意大利语到简体中文模板经验。具体书籍的制作日志、原文、译文、QA 和 EPUB 输出不得写入本文件。

## Salgari《Le tigri di Mompracem》实践入口

status: "TRIAL_LESSONS_STARTED"

### 初始预期

- Sandokan 系列属于强情节冒险小说。模板必须同时控制动作推进、对话称谓、殖民时代地名/族群/宗教词和中文阅读节奏。
- 试译应优先选择句法密集、动作链密集、殖民语境和感叹/对话较多的章节，而不是只选开篇。
- 每章译后质量控制必须把“中文是否顺、有趣、不费劲”作为硬要求，但不能把海事、武器、殖民机构、地理和族群称谓随意通俗化。

### 2026-05-31 第 23 章试译复盘

- 第 23 章 `Yanez alla villa` 是合适的最难试译章：它同时包含潜入伪装、长对话、女性人物心理、Sandokan 身世辩护、英殖民护卫队调度和结尾伏击战。意大利语模板不能只准备“文学句法”规则，还必须准备“冒险叙事动作链”和“殖民时代称谓”规则。
- Yanez 的中文声调不能译成严肃报告。他的核心功能是冷静、机智、带一点调侃；即使在欺骗勋爵时，也要让读者感到他在临场表演。
- Marianna 的段落不能只译成“等待被救”。她同时有反抗、恐惧、对叔父的亲缘牵连、对未来的不确定和对 Sandokan 的选择。中文润色要保留这种矛盾，不把她压成单一恋爱功能。
- Sandokan 身世叙述是本书重要合法化链条：王族出身、殖民势力/本地盟友击垮其王国、家人被杀、流亡、复仇、成为马来亚之虎。译文可以顺读，但不能把这段压缩成“他有悲惨过去”。
- 战斗段必须先锁动作顺序再润色：口哨 -> 双侧枪声 -> 人马倒地 -> Yanez 护住 Marianna -> 勋爵开枪/决斗 -> 英国士兵受命杀 Marianna -> Sandokan 冲入救人。若先追求“热闹”，很容易改乱因果。
- 自动扫描是必要但不充分。第 23 章 round 1 发现英文 `barricade` 残留并修复；这证明每章 control 必须同时做裸外文扫描和人工语义复读。
- `prahos`、`kriss`、`rajah`、`Tigre della Malesia`、`Labuan`、`Sarawack`、`Varauni` 等不能等全书翻完再处理。试译阶段就要进入术语表，并用 `review` 状态阻断终稿前遗漏。
- “顺、有趣、不费劲”不是把术语压扁。比如 `kriss`、`prahos`、`rajah` 不能都译成“刀”“船”“王”；正文可自然读，术语表和短注要承担精度。

### 待试译后回填

- 第 1-3 章正式生产证明，Salgari 开篇常把环境、战利品陈设、人物肖像和动作预告叠成很长的铺陈句。中文可以拆段，但不能删掉“物象堆叠”本身，因为它承担冒险小说的奇观感和海盗巢穴的危险氛围。
- 船战段应先建立动作表，再润色中文：备战 -> 发现目标 -> 分船包抄 -> 炮击桅杆 -> 小艇逃跑 -> 接舷 -> 投降 -> 慷慨赠偿。若只追求中文热闹，容易把因果和位置关系改乱。
- `prahos` 在正文中暂统一为“马来帆船”，比“帕劳船”更自然；但仍应保留 `review`，终稿前按全书海事语境决定是否需要更具体船型译法。
- 族群称谓、殖民时代地名和自然名物必须边译边补术语表。第 2-3 章一次性暴露 `battias`、`dayaki`、`negritos`、`Sunderbunds`、`durion`、`tucani`、`arenga` 等，不能等全书结束再补，否则很难追踪变体。
- 第 4 章巡洋舰战斗说明，海战章节必须把“相对位置”和“舰船动作”作为质量检查对象：巡洋舰堵河口、退后避免接舷、海盗船退入小河、夜间贴岸逃离、磷光暴露、再接舷、桑多坎跳海。中文润色不能只检查句子顺，还要检查空间链条是否仍成立。
- 蒸汽战舰和帆船混战会集中出现 `ruote`、`sperone`、`tambura`、`cubie`、`argano`、`vela latina`、`trinchetto`、`bompresso` 等术语。模板执行时应要求每章后即时补 `glossary/terms.csv`，并用 `review` 标记不确定海事词。
- 第 5 章从外部海战转入身体极限和热病谵妄。模板需要明确：心理/幻觉段的“顺读”不是把重复删光，而是保留原文狂热、呼喊、虎豹象征和复仇回环，同时用中文段落和气口让读者跟得上。
- 负伤求生段必须核对身体动作和医学位置：漂浮、潜伏、抓残骸、登岸、清洗伤口、第五根肋骨下中弹、发热、谵妄。不能为了文学化把生理逻辑改乱。
- 第 6 章首次见到 Marianna 时，原文采用十九世纪冒险小说式的强凝视和浪漫夸张。中文不能把它现代化成轻对白，也不能任意削弱“马来亚之虎第一次失控”的功能；应保留震动、停顿、重复名字和最后承认爱情的戏剧性。
- 桑多坎在 Guillonk 面前的伪身份线需要专门检查：`principe malese`、`sultano di Shaja`、`sultano di Varauni`、Romades 登岸说法、被海盗袭击的假叙述，都要前后一致，不能因润色泄露真实身份。
- 第 7 章的情感冲突不是普通恋爱段，而是“海盗身份/复仇事业/族群仇恨”和“留在 Marianna 身边”的正面决斗。控制记录必须检查这条心理链：愿意留下 -> 试图逃走 -> 拾起花 -> 围栏前崩溃 -> 返回房间。
- Marianna 背景段包含反海盗战争、海上童年、被迫定居、教育转变、慈善救助和纳闽明珠称号来源。翻译时不能只把她当恋爱对象处理；她的无畏、善良和旧日骄傲都是后续人物关系的依据。
- 第 8 章猎虎段把表白和动作承诺绑在一起：Sandokan 先以王后、王位、船、士兵、火炮许诺，再立刻用 `kriss` 徒手杀虎兑现“虎皮归你”。翻译控制不能把表白当成可删减的夸张，也不能把搏虎动作简化成“他杀了老虎”。
- 海军军官第一次对“马来王子”身份产生怀疑，这是后续风险线。逐章控制应记录类似识别钩子，避免后文称谓或伪装线断裂。
- 第 9 章是真名揭露和背叛章，必须完整保留 Sandokan 的自我辩护链：不是为贪婪做海盗，而是被白人势力夺国、杀亲、逼上海路后的 `giustiziere` 和复仇者。若这段被压缩，Marianna 接受他的逻辑会失真。
- 宴席盘问是悬疑线，William Rosenthal 的问题、Guillonk 赴 Vittoria、Marianna 私下要求坦白、Guillonk 穿军服回来，都要作为同一条识破/背叛链记录在章节控制中。
- 第 10 章追捕/逃亡段需要单独的空间逻辑门禁：客厅、走廊、房间、窗口、花坛、园中小楼、围栏、森林、黑水溪、树上藏身和樟树拦路都影响动作可信度。中文不能把追捕泛化成“逃进树林”，还要保留 Sandokan 的战术判断：不直奔西方最近海岸，而是折向南方，并借溪水切断犬只追踪。
- 第 11 章伪装/欺敌段必须把“角色知道什么”作为忠实度硬项。`non ignorava` 一类否定结构很容易误译，若把 Yanez 知道 Sandokan 去纳闽译反，就会破坏 Giro-Batol 上岸寻找的因果。伪装段还要同时记录真实路线和假路线：真正脱身、北岸假目标、红山假踪迹、东向假足迹和赏金诱饵。
- 第 12 章这类民俗/食物说明要分两条线控制：一是 `pombo`、`blaciang`、`gomut`、`calamus`、`nepentes` 等自然名物和材料必须进术语表并标出 review；二是殖民时代叙述中的食物和族群偏见应忠实呈现但不额外猎奇扩写。中文要让说明读得顺，但不能把作者偏见改写成现代百科口吻。
- 第 13 章海上返航段说明，Salgari 的海事动作不能只按“遇到敌船”概括。模板执行时要强制检查航灯识别、风向、右舷倾斜、炮艇靠近、停止明轮、Romades 假任务、调帆返航和登陆岩崖等链条；否则会破坏 Sandokan 用伪装身份脱身的可信度。
- 第 14 章心理/醉酒段说明，Salgari 的激情独白不能压成现代心理说明。模板执行时要强制检查情绪和论证链：战败报告 -> Marianna 理想化 -> 爱情与海盗身份冲突 -> Yanez 试探 -> 营救计划 -> 独饮麻醉 -> 威廉幻觉 -> 毁物醉倒。中文要保留歌剧式夸张和反复，但用句群气口控制可读性，不能新增原文没有的心理解释或酒醉意象。
- 第 15 章情报/审问段说明，返航船损和俘虏供词必须同时控制：受损马来帆船从岬角后出现 -> Pisangu 报告在河口抓获下士 -> 炮艇封锁和船战 -> 下士供出 Guillonk/Rosenthal/Vittoria 防线 -> Marianna 被迫婚讯 -> 远征队和守岛防务分配。模板执行时要特别检查专名和头衔一致性，例如 `Guillonk` 不能在“吉伦克/古伊隆克”之间漂移，`baronetto` 应按英国语境和既有伪装线统一为“准男爵”。
- 第 16 章风暴/登陆段说明，海事动作链必须先画清楚再润色：三船出征 -> 弱风加帆 -> 风暴增强 -> 英舰炮击 -> 发现纳闽 -> 入小湾 -> 借巨浪放小艇 -> 船出湾、人登岸 -> 次日找旧河口 -> 夜入 Guillonk 园子 -> 在中国式亭子留字条。`ribolla`、`alla cappa`、`scialuppa`、`flutti di fondo`、`boscelli` 等词如果不进术语表，很容易在后文漂移。情感词也要按语境判断，例如 `febbre` 在这里是急迫热情，不应机械沿用病理“热病”。
- 第 17 章夜间约会说明，Salgari 会把爱情场景写成潜入/囚禁/追捕的一部分。模板执行时要同时检查三个节奏：暴风后的生存等待、园中潜行制伏哨兵、铁栅窗下的重逢对话。窗下激情可以保留歌剧式夸张，但不能新增原文没有的心理解释；`inferriate`、`pergolato`、`padiglione`、`attap` 等物件必须进入术语表，因为它们直接决定第 17-18 章的动作连续性。若原文章末以逗号断章，control 要记录其与下一章的接续关系，不能擅自补成完整句。
- 第 18 章追捕/温室段说明，Salgari 的惊险段常带喜剧性，不应把 Yanez 的玩笑、士兵迷信和炉膛藏身的荒诞感抹平。模板执行时要强制检查空间链：花架跃下 -> 园中逃跑 -> 围栏外埋伏 -> 改藏园内 -> 温室 -> 巨大炉膛 -> 士兵搜查 -> 煤灰脱险 -> 再靠近小楼。`serra`、`stufa`、`fuliggine`、`nerofumo`、`casuarina`、`Belzebù`、`Madonna del Pilar`、`mille sterline` 等应即时入术语表；殖民时代称谓如 `negri` 要忠实但克制，不能猎奇扩写。
- 第 19 章红衣兵幽灵段说明，标题中的“幽灵”来自英军对两个海盗行踪的误判和迷信化想象，不是超自然事实。模板执行时要检查章题功能是否在正文对话中成立，而不要额外写解释。动作链要锁住：哨兵喝问 -> Sandokan 撤退 -> 白天搜园 -> 抓单兵 Barry -> 枪遗落暴露 -> 士兵围搜温室 -> 炉中威胁俘虏 -> 撞破炉壁突围。`buà kadangsa`、`Barry`、`scozzese`、`upas` 这类看似小的名物/配角词也要即时入术语表，因为后续逃亡和英军视角可能复用。
- 第 20 章穿越森林段说明，Salgari 的自然奇观不是可删减背景，而是逃亡动作的实际地形障碍。模板执行时要把植物网、树上攀行、犬追踪、旧路消失、黑水溪和章末双重猛兽危机连成动作链检查。`gambir`、`piper nigrum`、`bua mamplam`、`bigit`、`maias`、`hariman-bintang` 等自然名物应即时入术语表并标记 review；中文可以自然化为儿茶藤、黑胡椒藤、马来猩猩、斑豹等，但不能把章末明确动物泛化成“野兽”。本章还显示“顺、有趣、不费劲”需要靠句群拆分和节奏控制，而不是删掉热带植物、鸟兽和殖民时代猎犬说明。
- 第 21 章黑豹袭击段说明，动物搏斗本身是情节机关，不是可压缩的背景奇观：`hariman-bintang` 被说明为 `pantera della Sonda`，`maias` 被说明为 `urang-outan`，并直接引出 Paranoa 误入危机和三方枪击救援。模板执行时要强制检查“豹上横枝 -> 猩猩摇枝 -> 豹反扑抓伤 -> 猩猩抓尾摔豹 -> Paranoa 靠近 -> 双枪救援 -> 补枪击毙”的动作链。船只回合段还要检查海事隐蔽细节：两堆火信号、白灯变红灯、两次转舷入湾、芦苇旁抛锚、放倒桅杆、固定索和活动索、树枝叶子伪装。`pantera della Sonda`、`urang-outan`、`fanale rosso`、`manovre correnti` 等应即时入术语表。
- 第 22 章俘虏段说明，Salgari 的“计划章”不能译成静态说明，要检查战术链和通讯链是否可执行：Ikaut 回船守候、每四百米布一名哨兵、命令逐段传回 praho、路旁营地监视通往 Vittoria 的道路、绳索设伏截获 sipai 中士、从头盔衬里取出 Rosenthal 来信、Yanez 放弃伪造信件改走口头欺骗、换装入 villa。模板执行时要特别记录“伪装身份知道什么/要骗谁/如何回传命令”，否则第 23 章潜入别墅会失去因果。`Ikaut`、`sergente dei sipai`、`sciabola`、`elmo`、`fodera`、`calamaio`、`barcarola` 等应即时入术语表。
- 第 24 章“猛虎的妻子”说明，爱情段和海战段不是两块可分开的内容。Sandokan 等天亮、亮旗、拒绝还击、命令缩帆、横风停住、用臼炮击毁左舷明轮罩，都是为了让敌人看见“马来亚之虎”和他的妻子。模板执行时要先锁动作链：月夜逃离 -> 安慰 Marianna -> Yanez 发现巡洋舰 -> 舱房铁板保护 -> 搬臼炮 -> 等黎明 -> 旗号交换 -> 暴露在炮火下 -> 白旗劝降和红旗回应 -> 风起加速 -> 缩帆诱敌靠近 -> 横风停住 -> 臼炮命中明轮 -> 展示 Marianna 为妻 -> 转向西去。`mortaio`、`bomba da otto pollici`、`terzaruoli`、`griselle`、`tambura di babordo`、`scotta`、`in panna` 等应即时入术语表，并标出需要终稿复核的海事词。
- 第 25 章“在孟普拉森”说明，胜利后的返航段本质是事业终结的心理章节，不是简单过渡。模板执行时要检查三条线是否合一：一是敌船受创后短暂安全，二是 Sandokan 判断 Guillonk 将组织小舰队攻岛并决定最后一战，三是抵达后确认孟普拉森已被趁虚袭击。中文润色不能把“失去海、岛、船队、名声、权力”和“为 Marianna 放弃一切”的链条压成一句感慨。`clippers`、`coronamento di poppa`、`flottiglia`、`olandesi`、`pennone di trinchetto`、`bastioni` 等应即时入术语表。
- 第 26 章“孟普拉森的王后”说明，Marianna 的称号不是装饰性浪漫称呼，而是由群体仪式建立的政治/情感身份。模板执行时要检查完整链条：英军趁 Sandokan 不在袭岛 -> 海盗要求报复 Labuan -> Sandokan 因 Marianna 阻止复仇 -> 海盗改为宣誓保护她 -> Sandokan 计划最后一战后离岛 -> 防御工事和财富撤退同步准备 -> 午夜集会公开告别海盗事业 -> Marianna 主动把 Mompracem 作为祖国 -> 武器交叉并称她为王后。`presidio`、`squadra`、`ridotto`、`terrapieni`、`trincee`、`palizzate`、`diadema di brillanti` 等应即时入术语表。
- 第 27 章“炮轰孟普拉森”说明，炮战章不能只按“激战后撤退”概括。模板执行时要先锁空间和火力链：全岛备战 -> 三道棱堡和中央内堡 -> 敌方英荷西瓦劳尼联合舰队 -> 海盗旗被击落预示失败 -> 第一轮齐射压住舰队 -> 击毁瓦劳尼 praho 和西班牙炮艇 -> 英荷增援到来 -> 第一道防线毁 -> 指挥巡洋舰被臼炮击沉 -> 左右炮台沉默 -> 火药库爆炸 -> 中央内堡坍塌 -> Sandokan 第一次下令撤退。`batterie`、`gabbioni`、`trabocchetti`、`mine`、`polveriere`、`corvetta`、`cutter`、`brigantino`、`feritoie`、`imbroccati` 等应即时入术语表。
