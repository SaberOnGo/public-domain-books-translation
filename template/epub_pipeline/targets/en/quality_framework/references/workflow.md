# English Translation Workflow / 英文翻译流程

1. Read common policies and the source-language template; establish source/rights evidence and the output editions.
2. Record book-specific research, genre, narrator, intended readership, English convention, terminology, names, images, and ambiguity watchlist.
3. Before full translation, trial at least opening, action, technical/cultural, and rhetorical/closing passages. Produce A (close), B (idiomatic), C (literary), D (integrated) candidates with source-supported comparisons. Then test three representative information-dense, emotional, and terminology-heavy samples. Both trial reports must PASS.
4. Lock translation contract, terminology, proper-noun discovery/decisions/occurrences, and persistent canonical units before body production.
5. Translate stable paragraph units with compact context. Immediately after each chapter merge, run full source-target comparison and English-only reading. Inspect voice, fidelity, polysemy, titles, notes, images, terminology, and production traces. Preserve every failed round; fixes require a new whole-chapter round.
6. Record fidelity, readability, imagery, terminology, chapter control, independent unit audits, and chapter gate. Promote only current zero-issue PASS chapters; never edit projections to hide a canonical defect.
7. Write production specification, build and review an illustrated sample when images exist, then build both requested full editions. Run all common/private technical gates and EPUBCheck.
8. Conduct literary rereading of openings and the whole book, independent final reviews, and post-EPUB stratified random review by two independent agents. Audit discovered families throughout reader-visible content, close them locally, merge reusable lessons, rebuild, and use new seeds. Default exit requires two current-run consecutive PASS rounds and the strong validator.
9. Rebuild after closure, create versioned public or private artifacts as appropriate, verify hashes and delivered scope, write retrospective and template suggestions, and only then mark DONE.

依上述阶段顺序完成译前研究、四版试译、小样本、合同锁定、逐章全量审校、样章制作、两版构建、独立审阅、分层抽检、问题族闭环、版本化产物与复盘。任何 PASS 必须来自已执行且绑定当前稿件的检查，不能由脚本批量编造。
