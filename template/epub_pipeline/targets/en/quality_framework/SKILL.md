# English Translation Quality / 英文翻译质量

Read this framework's references before translation, then the applicable source-language template. Use `skills/expert-translation-quality/SKILL.md` for source-supported sense selection and downstream-context review. Use `skills/translation-quality-defect-families/SKILL.md` for recurring defects.

Translate complete canonical units. Registered entities use locked `{{pn:entity_id}}` tokens. The sole merger owns the canonical store; derived chapters and bilingual blocks must share the same target. Preserve source paragraph boundaries, point of view, causal structure, uncertainty, action, metaphor, and tone.

Review target-only prose first, compare the source next, revisit ambiguous senses with later context, then rebuild weak prose and recheck the whole chapter. An independent reviewer must give specific per-unit evidence for omissions, additions, boundary contamination, and numbers/names/negation/notes. A fix round never doubles as PASS.

英文须像完成的书稿，而非中文句法的逐词替换。依次执行英文独立阅读、原文对照、后文判义回看、句法重建与整章复查；译者不得为自己的章节签发独立审计 PASS。
