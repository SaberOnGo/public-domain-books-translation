# English Target-Language Quality Framework / 英文目标语言质量框架

These rules apply to translation into English from any source language. They are not a source-language template. Chinese, Arabic, French, Japanese, and other interference mechanisms belong in the matching language-pair directory.
本框架用于各语言译入英文；中文、阿拉伯语、法语、日语等源语言干扰规则应放在对应语言方向模板中。

Read `SKILL.md`, `references/quality_standard.md`, `references/workflow.md`, and `references/title_punctuation_and_heading_style.md`. Use `templates/evaluation_rubric.md` for trials, chapter reviews, and final quality evidence. `templates/chapter_translation_prompt.md` and `templates/revision_prompt.md` are compact execution interfaces, not substitutes for the shared pipeline.

All common source, rights, canonical-unit, independent semantic audit, chapter control, assets, bilingual, EPUBCheck, random review, versioning, and retrospective gates remain mandatory. Private use changes storage and use boundaries, not English quality. A book must specify its variety of English; use contemporary international English with a documented consistent spelling convention when the source supplies no reason for another variety.
所有 common 门禁继续适用。私人自用不降低英文质量；每本书须记录英文变体与拼写约定。
