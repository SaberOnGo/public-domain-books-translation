# AI 辅助文学翻译工作流

## 阶段 0：译前研究

为每本书建立：

- 作者画像：身份、时代、写作目的、读者对象。
- 文体画像：纪实、回忆录、旅行、论文、小说、演讲等。
- 叙述声音：冷静、热烈、讽刺、庄重、口语、自辩、抒情。
- 术语表：专名、专业术语、行业术语、历史称谓。
- 敏感点：种族、殖民、性别、宗教、民族称谓。

译前研究分三层：

1. 简体中文目标语言翻译研究：面向所有译入简体中文的书，维护在 `template/epub_pipeline/targets/zh-Hans/quality_framework/references/`。
2. 本书专项翻译研究：面向某一本书，输出 `metadata/book_specific_translation_research.md`。
3. 预翻译试译：面向本书最难的若干段，输出 `qa/pretranslation/pretranslation_report.md`。

三层必须逐级通过。预翻译失败时，不能直接开始正式翻译，应判断失败原因并回溯：

- 如果失败来自通用原则缺失，回到通用翻译研究阶段。
- 如果失败来自本书词法、文体、历史语境判断不足，回到本书专项翻译研究阶段。
- 如果失败只是个别表达不够好，留在预翻译阶段继续重译。

## 阶段 0.5：预翻译试译

正式分章前，必须建立 `qa/pretranslation/`，至少试译：

- 开篇或定调段。
- 典型动作/场景段。
- 术语或历史敏感段。
- 一个修辞强、结尾强或象征物强的句子。

每个样本必须给出 A/B/C/D 四版，并说明为什么 D 可以作为正文候选。

`qa/pretranslation/pretranslation_report.md` 未明确 PASS 前，不得进入正式章节翻译。

## 阶段 1：小样本测试

先选 3 段：

- 信息密集段。
- 情绪/修辞强段。
- 术语/文化负载重段。

每段生成 3 个候选译文：

- A：忠实版。
- B：中文可读版。
- C：文学润色版。

然后融合成 D：终稿候选。D 必须评分通过，才开始整章生产。

如果用户提供优秀人译短样本，例如杜拉斯《情人》开头的王道乾译本，应先做私有对照测试：

- 只学习其中文节奏、叙述克制、重复组织和关键句收束。
- 不复刻受版权保护文本。
- 不把不同体裁强行翻成同一种腔调。
- 将结论写入 `qa/benchmark/`，作为本书翻译的风格约束。

## 阶段 2：分章翻译

每章分为段落或小段落组，不逐句替换，也不把大块文本一次性交给模型硬吞。翻译调用必须瘦身：只给当前原文、文体画像中最关键的 5-8 条、当前段命中的术语和必要上下文，不把 release、版权、EPUB、lint、QA 文件结构等流程规则塞进翻译 prompt。

每个段落组先做内部判断：

- 原文意图摘要。
- 语气判断。
- 难点说明。
- 意象词/场景词判断：列出本段不能平译成解释词的关键词。
- 译文。

最终只把译文写入正文文件；分析写入 QA 文件或内部记录，不得混入读者正文。

翻译阶段质量优先级：

1. 译文首先必须像一本自然的中文书，普通读者能顺畅朗读。
2. 忠实原意、事实、语气、叙述立场和人物关系。
3. 术语一致，但只有 `locked` 术语必须硬性固定；`preferred` 术语可按上下文自然变体。
4. 出版格式合规；格式问题不得压倒中文可读性，留给后续门禁修正。

必须允许自然中文句法重组：

- 英文长句可拆成中文句群。
- 从句顺序可按中文阅读顺序重排。
- 过碎的中文短句可合并成自然句。
- 英文抽象结构可转为中文自然叙述。
- 信息焦点可前后调整，但不得改变事实、情绪强度或叙述立场。

长句控制是翻译阶段目标，不是 EPUB 后期排版目标。普通叙述句不应连续堆成长串；若一个中文句子读完需要明显换气，应拆成两句或三句，并保留因果、转折、递进和时间推进。

章节开头、结尾、高现场感段、关键对话、术语重段和上一轮 QA 指出机械的段落，必须在内部做 A/B/C/D 多候选融合：

- A：忠实版。
- B：中文阅读版。
- C：文学润色版。
- D：融合终稿。

正文只保留 D，不保留候选过程。

每章写入 `chapters/translated/{chapter}.md` 后，必须立即只针对该章进入“每章译后，全量检查并修复节点”，不得先翻译下一章来把该章问题留到全书后期。

## 阶段 3：五轮返工

第一轮：中文独立润色。

- 不看原文，先只读译文，判断它是否像一本自然的中文书。
- 修复大段长句、不断气句、英文句法残留、说明书腔、学术腔堆叠和动作清单。
- 随机朗读至少 20 句；明显拗口超过 1 句则本轮失败。
- 中文独立阅读评分必须 >= 4/5；否则不得进入下一轮。

第二轮：准确性。

- 查漏译、误译、数字、时间、人物关系。
- 对照原文校准第一轮润色是否改错事实、语气、动作强度或叙述立场。

第三轮：中文性。

- 删除英语句法残留。
- 拆长句，重排信息顺序。
- 检查术语硬套是否压低中文可读性；只有 `locked` 术语必须硬锁，`preferred` 术语可自然变体。

第四轮：文学性。

- 检查节奏、画面、收束句、过渡句。
- 重写乏味句和直译句。
- 检查正文关键句是否用了“只说明、不成像”的懒译词；能换成准确且更有画面的词时，必须更换。

第五轮：出版性。

- 标题、段落、术语、标点、译注、EPUB 格式。
- 标题必须按 `references/title_punctuation_and_heading_style.md` 检查：长标题要拆成短目录题名、页面主标题和可选副标题；不得留下半截标题或机械破折号链。
- 出版文本 lint：编码、空格、旧纸书页码目录、分号滥用。

## 阶段 3.5：每章译后全量检查并修复节点

本节点是当前章文字硬门禁，写入 `qa/chapter_controls/{chapter}.control.md`。它必须在每章译后立即执行，并且在未通过时阻止进入下一章翻译、后续审校和 `chapters/final/`。

必须检查当前章整章，不得检查成全书门禁，不得只检查抽样段落，也不得只检查用户点名项目。检查范围至少包括：

- metadata、nav、目录、章节标题、页面标题和副标题会不会被本章内容污染。
- 正文是否准确、完整、自然、通俗、易懂、有节奏，不拗口、不学究腔、不机器翻译腔。
- 注释是否必要、清楚、不过密；脚注数字、译注、术语说明不会并入正文造成误读。
- 名词术语、人名、地名、机构名、历史制度名、变量名是否中文领头；历史术语、制度名、身份称谓、专业术语和文化负载词不得无必要地写成 `中文译名（source term）`。必要原词优先放本章译注、章末注或术语表，并用正文注号指向；正文括注原词必须有必要性理由。
- 是否按 `glossary/terms.csv.forbidden_body_renderings` 逐项扫描正文，并把扫描结果写入 `qa/chapter_controls/{chapter}.control.md` 的术语呈现审计表。
- 图表、公式、表格、图片、图注、表注、alt 文本和读图/读表说明等当前章文字接口是否足以让中文读者在 EPUB 内理解。
- 样式、标点、空格、分号、旧纸书页码目录、可见分隔符、乱码、英文残留是否符合模板门禁。
- 读者可见内容是否包含生产说明、AI 痕迹、项目内控语或不该公开的版权/私人模式文字。

每轮必须记录：

- `round`、`score`、`status`。
- `checked_scope`：实际检查了哪些范围。
- `asset_route_status`：`none`、`text_fixed`、`routed_to_asset_gate` 或 `blocking_text_issue`。复杂图表、表格、公式和图片资产问题必须路由到资产/技术门禁。
- `blocking_issues`：P0/P1/P2、事实/术语/当前章文字接口错误、读者不可理解、模板硬门禁失败。
- `fixes_applied`：修复摘要和文件位置。
- `remaining_risk`：剩余风险或明确无剩余阻塞。
- `allow_next_chapter`：`true` 只可在最近一轮无未关闭阻塞问题，并且“无问题或评分不小于 75 分”时写入；若项目/profile 有更严格规则，按更严格规则。分数不能抵消 P0/P1/P2、读者难以理解、事实/术语/文字接口错误或模板硬门禁失败。

图表、表格、公式和图片在本节点只做当前章文字接口检查与资产分流。图题、表题、正文引用、alt text、变量、单位和读者说明影响本章理解时，必须在本节点修复；重绘、OCR、裁剪、数值复核、公式排版、资源路径或 manifest 问题应写入 `qa/assets/{chapter}.asset_followup.md` 或 `qa/technical/{chapter}.diagram_table_audit.md`。已路由问题阻止 `chapters/final/`、构建和 release，但不让当前章译后文字门禁无限循环。

如果未通过，必须修复并追加一轮同节点复查，直到最近一轮通过。不得覆盖旧失败记录。

## 阶段 4：门禁

任何章节不满足以下条件，不得进入 `chapters/final/`：

- `qa/chapter_controls/{chapter}.control.md` 存在，记录每章译后全量检查并修复节点，且最近一轮允许继续。
- 准确性无重大错误。
- 没有明显直译腔。
- 随机抽取 20 句朗读，明显拗口不超过 1 句，且关键句不能不断气。
- 中文独立阅读评分不低于 4/5；“准确但不像中文书”不得 PASS。
- 章节末尾有 QA 报告。
- 术语与前文一致。
- 标题、开篇、结尾、危险现场、象征物和人物评价中没有懒译词。
- 章节标题没有机械照搬原文标点，没有半截截断，没有在 EPUB 导航中塞入长标题链。

门禁报告必须写入 `qa/gates/`。只有报告明确 PASS 的章节，才能进入 `chapters/final/`。

进入 EPUB 构建前，还必须运行：

```powershell
node scripts/publication_lint.js --target=zh-Hans --write-report
```

如果 lint 报出分号滥用、中文字符间异常空格、旧纸书页码目录或编码污染，必须先修正文稿或制作规则，再重新构建。
