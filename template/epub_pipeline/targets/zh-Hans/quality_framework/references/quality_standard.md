# 译文质量标准

## 总目标

译文要像一本真正由优秀中文译者写出来的书，而不是英文文本的中文影子。

优秀译文的参照不是“更华丽”，而是中文文本自身有生命。王道乾译杜拉斯《情人》的开头可作为私有方法样本：它可学习的是节奏、克制、回环、长句内部的呼吸，不是照搬腔调。

## 五维标准

### 1. 准确

- 人名、地名、时间、数字、方向、因果关系必须正确。
- 不因追求优美而改写事实。
- 隐喻、反讽、强调、迟疑等语气必须保留其功能。
- 多义词、习语、称谓、术语和语法关系必须等后文语境判清后回看复查；如果后文推翻了前文选义，前文必须修订。

### 2. 通达

- 不保留英文从句堆叠。
- 中文句子有呼吸，长短错落。
- 段落之间有自然推进，不像逐句拼贴。

### 3. 风格

- 先判断原文声调：自述、回忆、讽刺、庄重、冒险、抒情、报告。
- 中文声调要与原文功能相当，而不是每本书都翻成同一种“说明文”。
- 纪实探险文本要有现场感、紧迫感和人物气息。

### 4. 审美

- 避免“旗褶”“站在某某之下”这类直译腔。
- 原文意象在中文里难读时，转译其效果。
- 关键句要反复打磨，尤其是章节结尾、人物判断、情绪转折。
- 不要为了“雅”而把文字涂脂抹粉；雅首先来自准确、节制和节奏。
- 正文关键句优先选择有画面、有动作、有质感的中文词，而不是只完成说明功能的词。

## 形象词优先规则

翻译不是把英文词换成中文解释，而是让读者在中文里看见、听见、感到原文要造成的效果。

判断一个译法时，必须问四个问题：

1. 读者看到这个词，脑中有没有画面？
2. 这个词有没有时代、场景或情绪的附着力？
3. 它是否比普通解释词更容易被记住？
4. 它会不会为了生动而偏离事实？

如果 1-3 的答案是否定，且它出现在标题、章节开头、结尾、人物评价、危险现场、象征物或核心意象中，就不能作为正文终稿。

## 克制译注与常识误读

公版旧作里常有原文事实正确、但现代中文读者容易按今日常识误读的内容。译者必须先核对原文和上下文；确认不是误译后，再判断是否需要短注。

必须考虑短注的情形：

- 历史货币、物价和收入会被读者按现代币值误解，例如旧日元、法郎、先令、银元、钱、銭。
- 历法、丧葬、宗教仪式、官制、学校制度、交通制度等专有语境会被读成普通日期或普通词。
- 度量衡、年龄算法、婚姻/称谓/职业制度若不说明会改变人物处境判断。
- 原文数值看似反常，但上下文明确支持其时代含义。

注释必须克制：

- 优先使用正文注号加译注、章末注或术语表说明，例如 `术语[1]` / `术语（1）`，后文不反复注。
- 注号只允许 `[1]`、`(1)` / `（1）`、`注1` 三类体系；不得使用带圈数字、小圆圈“注”、裸 `译注：` / `脚注：` / `尾注：` / `附注：` 或句末裸数字。
- 重点专有名词按 `glossary/proper_nouns.csv` 管理；用户未设置时默认第一次正文自然出现写 `译名（原文）`，后续使用译名。标题、副标题和目录题名不计入正文首次出现。
- 不默认在正文写 `中文译名（source term）`。历史术语、制度名、身份称谓、专业术语和文化负载词应先给出自然中文译名或意译；原词、定义和译名理由放入译注、章末注或术语表。
- 只有不保留原词会造成明显误解、原词本身是论证对象，或译名分歧必须当场交代时，才允许正文短括注原词；这种例外必须在术语表、译注或 QA 记录中说明。
- 注释只解决误读，不写百科条目，不讲研究史，不替读者做文学解释。
- 能从上下文自然理解的时代设施、地名、普通器物，不因“老旧”就加注。
- 不要把读者当小白；注释密度过高会破坏小说阅读，应视为质量问题。

## 核心规则：生动必须有依据，简洁必须有气息

优秀译文要同时避开两个陷阱：

### 规则 A：意象增强必须有原文依据

可以增强原文已经有的东西：

- 已有体感：冷、痛、累、灼烧、窒息。
- 已有动作：拖、推、钻、穿、摔、赶、追。
- 已有空间关系：在……之下、越过、逼近、退回。
- 已有象征功能：旗帜、船名、极点、荒原、黑夜。

不可以凭空添加原文没有的东西：

- 新的比喻物。
- 新的声音。
- 新的动作强度。
- 新的心理判断。
- 新的场景气氛。

判断句：如果删掉新增意象后，译文立刻失去全部魅力，说明魅力不是从原文转化出来的，而是译者另写出来的。

### 规则 B：简洁不能变成省字式翻译

中文叙事需要呼吸。原文短句可以译得紧，但不能译成清单。

不合格：

> 冷，风割着人。解绳，卸载，取出手摇钻和钻头，另钻新孔。

问题不是每个词错，而是中文没有叙述气息，像提纲。

合格方向：

> 天冷得厉害，风割在身上。你先得解开捆索，把载荷卸下来，再取出手摇钻和钻头，另钻新孔。

它仍然紧，但像人在讲述一件正在发生的事。

## 意象增强边界

形象词优先不等于任意发挥。译者可以把原文已经包含的感觉、动作、空间关系、象征功能，在中文里转成更可感的表达；但不能凭空添加原文没有的比喻、物体、声音或情节。

允许：

- 把 `Cold and windy.` 译成“冷，风又硬。”因为“硬”是对风寒体感的中文化转写。
- 把 `under the folds of Old Glory` 译成“星条旗的旗影将永远投在它之上”，因为它保留了旗帜覆盖/笼罩的空间关系。
- 把 `Our breath was frozen to our hoods of fur` 译成“呼出的气结在皮兜帽上”，因为画面来自原文。

谨慎作为候选、一般不进正文：

- “凌厉的寒风，如同坚硬的碎石，砰砰地撞击到人的身上。”

这类译法有画面，但 `碎石`、`砰砰撞击` 是译者新增意象。除非上下文已有类似冲撞、敲击、碎冰、石块声音，否则不能作为正文终稿。它可以作为试译阶段的“发挥版”，帮助寻找方向，但最终译文必须收回到原文许可范围内。

判定原则：

1. 新意象是否能在原文词语或上下文中找到依据？
2. 新意象是否改变了动作、材质、声音或情绪强度？
3. 删除新意象后，译文是否仍然有画面？
4. 如果必须靠新意象才好看，说明译者没有真正转化原文，而是在替原文写作。

## 省字式翻译警报

中文有节奏，不等于把句子压成提纲。原文短促时，可以保留紧张感，但译文仍要像人在讲述，不应像动作清单。

不合格表现：

- 连续使用“解绳，卸载，取出……”这类无主语、无气息的清单句，使读者觉得译者懒得组织句子。
- 为了避免直译而过度省略连接，导致中文不像叙事。
- 把纪实段落翻成操作说明书。

修正原则：

- 动作密集段可以短，但要有叙述者呼吸。
- 关键动作要补出自然中文动词，如“先”“再”“接着”“只好”“等到”。
- 原文是现场记录，不等于中文必须干瘪。

### 例：`Old Glory`

- `美国国旗`：事实正确，但偏解释，画面弱，像百科词。
- `星条旗`：事实正确，同时带图案、颜色、国家象征和历史感，更适合正文关键句。
- `Old Glory`：原文是美国国旗的昵称，带敬称、胜利和国家神话意味。

因此正文默认译为“星条旗”；只有在译注或说明文字中才解释为“美国国旗的昵称”。

### 例：探险文本中的词

- `ship` 在普通句中可译“船”，但有名字和性格时应译“罗斯福号”，让它像远征队的一员。
- `ice` 不总译“冰”；按场景区分“浮冰”“叠压冰”“新冰”“冰原”“冰脊”，让读者知道他们到底在穿越什么。
- `wind` 不总译“风很大”；按身体感译成“硬风”“顶风”“大风压着人走”等，但不得夸张到原文没有的程度。
- `dog-team` 不只译“狗队”；动作场景中可译“狗拉雪橇队”“狗队拖着雪橇”，让画面动起来。

### 5. 可出版

- 术语统一。
- 标点统一。
- 译者注位置明确。
- EPUB 目录、标题、段落能正常阅读。

## 优秀门槛不是及格门槛

随机抽检和章节复检里的 `80` 分只表示硬下限：低于 80 必须失败；超过 80 也不自动代表优秀。

专家级译文必须使用 `skills/expert-translation-quality/SKILL.md` 进行目标语独立阅读、原文忠实复核、翻译阶段多义词主动判义、多义词上下文回看和句法重建。章节 control 必须记录 `expert_level_review_status: "PASS"`、`polysemy_translation_stage_review: "PASS"`、`polysemy_context_review: "PASS"` 和 `polysemy_unresolved_count: 0`，否则不能作为优秀出版证据。

面向最终 release 或 private artifact 的简体中文译文，默认采用优秀出版线：

- 每个独立评审 Agent 的 `average_score >= 92`。
- 每个独立评审 Agent 的 `lowest_score >= 88`。
- 每个抽中样本都有逐项评分行；只写总评无效。
- `blocking_issue_count = 0`，`open_p0_p1_p2_count = 0`。
- `style_debt_count = 0`，`literal_explanatory_style_debt_count = 0`，`high_impact_style_debt_count = 0`。
- `qa/literary_style/literary_style_review.md` 必须 PASS；目标语独立阅读 5/5，朗读拗口句 0，未关闭文学性债务 0。

原作者序言、导言、开篇和首章是高影响区域。这里的“文学性不强、语言不顺口、怪、直译感重、句子平硬、解释腔明显”不应被当成普通 P3 建议；它会直接影响读者是否继续读下去。最终发布前，这些位置必须逐段做目标语独立复审，并在润色后回到原文校准，避免为了顺而加戏或改错语气。

分数解释：

- 80-87：意思基本可懂，但仍可能较硬、偏密、解释化、抽象腔或像翻译稿；不能作为最终优秀证据。
- 88-91：整体较好，但若最低样本不到 88 或平均分不到 92，说明仍有可见润色债务。
- 92+：才可作为随机抽检层面的优秀候选；仍需无阻塞问题、无缺失样本评分、无未关闭问题族。

评审中出现“可读但略硬”“较硬”“偏密”“略抽象”“稍显解释化”“英式分析腔”“像说明原意而不是中文书”等表述时，不能只写成温和评语后给高分。它们必须被归入 `style_debt` 或相应译文质量问题族；反复出现时，必须回到中文独立润色、句法重组或本书专项精修，而不是依赖分层随机抽检现场修补。

## 简体中文排版与标点硬规则

以下问题不是“风格差异”，而是出版前必须拦截的硬错误：

- 章节标题必须符合 `references/title_punctuation_and_heading_style.md`。机械保留多个破折号、半截标题、手机窄屏下过长的目录题名，都属于标题门禁问题。
- 普通中文正文中不得出现 ASCII 分号 `;`。
- 中文分号 `；` 只能用于确有并列分层关系的长句。不得把英文逗号、分号或连接词机械译成 `；`；一章内大量出现 `；` 时必须退回重修。
- 中文字符之间不得出现用于对齐的连续空格，例如“文字   这是”。普通正文中的中文字符之间通常不加空格。
- 旧纸书的页码目录、插图页码目录、靠空格对齐的名单或页码，不得原样进入 EPUB 正文。需要保留时必须改为真实目录、列表、表格或译注；已由 EPUB nav 表达的纸书目录应删除。
- 不得出现替换字符、mojibake、乱码字、半截 HTML/XML 或编码污染。
- 构建 EPUB 前必须运行 `node scripts/publication_lint.js --target=zh-Hans --write-report`。未通过时不得发布。

## 不合格译文特征

- 读起来像把英文语序换成中文词。
- 抽象词堆叠，没有具体画面。
- 句子能懂但不好读。
- 情绪强的地方译得平。
- 原文清楚的地方译得含混。
- 多义词或上下文依赖词在前文选错义，后文已经给出线索却没有回看修订。
- 旧时代术语未经判断，直接现代化或直接硬搬。
- 重点专有名词未按 `glossary/proper_nouns.csv` 执行，或标题中的专名原文被误当成正文首次出现。
- 历史术语、身份称谓或专业术语无必要地写成 `中文译名（source term）`，让正文夹杂大量源语词；可用译注解决却把解释塞进正文。
- 注号使用带圈数字、小圆圈“注”、裸注标签或句末裸数字，导致版式不规范或注释关系不清。
- 原文正确但明显容易造成现代常识误读时，没有核对并加必要短注；或相反，把可自然理解的时代词注释成研究笔记。
- 正文关键句使用了“美国国旗”“这项工作”“很冷”“走得很困难”这类只说明、不成像的懒译词，而原文实际有更强画面或情绪。
- 为了生动而添加原文没有的比喻或物象，使译文好看但不再可靠。
- 为了保留短促感而把中文压成动作清单，读起来像提纲或懒译。
- 出现可复现的问题族但只修单句，例如短句切断、比喻自撞、排比标点拖拽、代词指代不清、源语句法残留、术语漂移、标题超载、过度解释或加戏。

## 问题族沉淀

凡发现可复现的译文质量问题族，必须使用 `skills/translation-quality-defect-families/SKILL.md`。具体书籍证据留在本书 QA、章节控制、随机抽检修复日志或复盘中；可复用经验回填到该 skill，且应合并已有同族条目，不盲目重复追加。

审计顺序优先低 token：先用 `rg`、术语表、禁用正文写法、标题映射、抽样 manifest、章节控制记录和小上下文原文对照收集候选，再把候选片段交给 agent 复核。

## 例：直译病修复

原劣译：

> 北极点那野性、令人不安的神秘岁月，如今已经结束；从今天起，直到永远，它都站在“Old Glory”的旗褶之下。

问题：

- “旗褶”是生硬直译，中文没有稳定表达。
- “它都站在旗褶之下”画面不自然。
- “Old Glory”是美国国旗的昵称，正文关键句应优先转为有画面和象征感的“星条旗”；解释可放译注。

可接受译法：

> 北极点那片狂野而令人不安的神秘，从此揭开了面纱；自这一天起，它将永远归入星条旗所标记的历史。

更凝练译法：

> 北极点那狂野而不安的神秘时代，到此结束；从今以后，它将永远写在星条旗的历史之中。

## 专家级译文与上下文选义 / Expert Quality and Context Disambiguation

专家级译文不是“意思正确且大体顺”。翻译、审校和最终抽检必须按 `skills/expert-translation-quality/SKILL.md` 执行目标语独立阅读、原文忠实复核、多义词后文回看和句法重建。多义词、习语、称谓、术语和依赖后文判义的语法结构若被后文推翻，前文译法必须修订；保留未决歧义只能发生在原文本身有意暧昧，且译文保留了同等暧昧时。
